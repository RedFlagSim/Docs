# Compte et profil

Le profil relie votre logbook, vos classements, vos qualifications, vos médailles et Career XP au compte actuel.

Vous pouvez commencer avec un compte anonyme, mais pour jouer sur le long terme il est préférable de lier ou d'utiliser un Unity ID. Cela aide en cas de réinstallation, changement d'appareil ou récupération de progression.

Le profil peut contenir le nom du pilote, l'indicatif, le pays, le rang, le sous-niveau, Career XP, le temps de vol total et l'historique d'activité. Si vous changez de compte, le jeu utilise les records, qualifications et médailles de ce compte.
