# Manuel de pilotage sur mobile

Ce document concerne les appareils mobiles iOS/Android.

## Règle essentielle : tenir l’écran verticalement

C’est la base d’un contrôle précis de l’attitude :

![Règle essentielle : tenir l’écran verticalement](/assets/tilt-guide.png)

- ❌ INCORRECT : tenir le téléphone à plat ou horizontalement. Les axes de roulis et de lacet se couplent, ce qui empêche de distinguer fiablement les commandes de roulis.
- ✅ POSITION DE RÉFÉRENCE : tenir l’appareil à deux mains, écran perpendiculaire au sol et directement face à vous.

### Pourquoi faut-il le tenir verticalement ?

Le pilotage par mouvements doit pouvoir distinguer clairement l’axe de roulis. À plat, les axes de roulis et de lacet se couplent pendant le calcul d’attitude : le système ne peut plus déterminer fiablement lequel est commandé. La position verticale doit donc servir de référence.

## Commandes de vol

- Tangage (gouvernes de profondeur) : incliner le haut du téléphone vers vous pour cabrer et monter ; l’incliner vers l’avant, loin de vous, pour piquer et descendre.
- Roulis (ailerons) : tourner le téléphone à gauche ou à droite comme un volant.

## Joystick tactile virtuel

La version mobile propose aussi un joystick à l’écran en remplacement du pilotage par mouvements. Sélectionnez ce mode avant le vol si vous souhaitez garder l’appareil immobile.

![Joystick tactile virtuel](/assets/mobile-virtual-stick.jpeg)

- Tangage : tirer le joystick vers le bas pour cabrer et vers le haut pour baisser le nez.
- Roulis : déplacer le joystick à gauche ou à droite pour commander le roulis correspondant.
- Retour au neutre : relâcher le joystick pour qu’il revienne automatiquement au centre.

La tenue verticale et l’étalonnage ne concernent que le pilotage par mouvements. Avec le joystick tactile, vous pouvez tenir l’appareil dans toute position confortable.

## Préparation et conseils de précision

1. Établir la référence (étalonnage) : après l’entrée dans le cockpit ou avant le décollage, asseyez-vous confortablement, tenez l’appareil verticalement et sans bouger, puis touchez Calibrate Gyro dans le menu principal. L’angle actuel devient le zéro neutre.

    ![Préparation et conseils de précision](/assets/mobile-gyro-calibration.jpeg)

2. Stabiliser les commandes : en formation serrée, au ravitaillement en vol ou en combat rapproché, appuyez les coudes sur les genoux ou les accoudoirs. Cela filtre les tremblements du corps et permet une précision inférieure au degré.

## Mode d’édition de l’interface tactile

Touchez rapidement quatre fois une zone vide de l’écran pour ouvrir le mode d’édition. Vous pouvez aussi sélectionner `UI Editor` dans le menu principal.

![Mode d’édition de l’interface tactile](/assets/mobile-ui-editor.jpeg)

Dans ce mode, vous pouvez :

- Réorganiser les commandes : sélectionner et déplacer les éléments pour personnaliser la disposition.
- Activer la transparence : utiliser `CLEAR MODE` pour passer à la présentation transparente.
- Régler l’opacité globale : réduire l’obstruction de la vue par l’interface tactile.
- Configurer les MFD flottants : régler la taille et la visibilité des écrans multifonctions. Consultez la [documentation Touch UI du F-15C](/fr/Docs/aircraft/f15c/touch-ui.html#item-3) pour les commandes et le panneau d’édition.
