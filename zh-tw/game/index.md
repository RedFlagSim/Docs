# 遊戲系統

Red Flag Sim 將飛行員進度儲存在玩家帳號中。個人資料、生涯 XP、資格與勳章會跟隨帳號，而不是只保存在單一裝置。

## 儲存的內容

- 個人資料：飛行員名稱、呼號、國家、軍階、子等級、XP 與飛行時間。
- 生涯 XP：飛行、訓練、戰鬥活動、降落表現、加油、每日登入、資格與勳章所累積的長期進度。
- 資格：特定技能的限期或永久認證，例如機場降落或硬管空中加油。
- 勳章：飛行時間、軍階、戰鬥成果、降落與加油等里程碑的永久成就。
- 臂章：儲存在帳號收藏中的遊戲收藏品。

## 進度如何保存

遊戲不只依賴本機彈出通知或單次飛行畫面。分數、飛行紀錄、資格或勳章獲得後，都會與帳號進度核對並存入玩家歷史紀錄。

- 獎勵屬於目前登入的帳號。
- 開啟遊戲或飛行日誌時可更新進度。
- 暫時斷線可能延遲獎勵通知；紀錄同步後系統可補上。
- 部分未來的勳章或資格會保持鎖定，直到對應活動可用。
