# 遊戲系統

Red Flag Sim 會把你的飛行員進度保存到玩家帳號下。Profile、生涯 XP、認證資質和獎牌都屬於你的長期飛行記錄，而不是只存在於一次遊戲或本地提示中。

## 會保存哪些內容

- **Profile**：飛行員名稱、呼號、國家、軍階、子等級、XP 和總飛行時間。
- **生涯 XP**：來自飛行、訓練、戰鬥、降落、空中加油、每日登入、認證和獎牌的長期經驗。
- **認證資質**：對某項技能的認證，例如機場降落或硬桿空中加油。
- **獎牌**：永久成就，例如飛行小時、軍階進度、空戰結果、降落和空中加油里程碑。
- **臂章**：保存在帳號收藏中的遊戲內收藏品。

系統會把獎勵與目前登入帳號綁定。若同步或網路有延遲，提示可能晚一點出現，但記錄同步後仍可補發。
