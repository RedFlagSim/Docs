# 帳號與個人資料

Red Flag Sim 個人資料是進度、飛行日誌、排行榜、資格與勳章使用的身分。

## 帳號類型

可用匿名帳號快速開始體驗，但它依附於目前保存的帳號狀態。

長期遊玩請連結或登入 Unity ID。重新安裝、更換裝置或希望保留同一身分下的進度時，連結帳號是較穩妥的選擇。

## 個人資料內容

- 飛行員顯示名稱。
- 呼號。
- 中隊或飛行小隊資訊。
- 國家。
- 軍階與子等級。
- 生涯 XP。
- 總飛行時間。
- 用於進度計算的連續登入與活動歷史。

排行榜與公開展示只使用較精簡的公開資料，例如名稱、呼號、頭像、軍階、子等級與 XP。

## 保護進度

進度屬於目前登入的玩家帳號。切換帳號後，遊戲會切換到該帳號的資料、紀錄、資格與勳章。

匿名玩家應在累積重要的長期進度前考慮連結帳號，以保留飛行員身分並方便日後恢復進度。

## 資料更新時機

- 登入後。
- 開啟飛行日誌後。
- 完成飛行或技能活動後。
- 獲得生涯 XP 後。
- 取得或續期資格後。
- 解鎖勳章後。
