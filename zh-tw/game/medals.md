# 勳章

勳章是永久成就，與有期限的資格不同，取得後不會過期。

## 取得方式

保存的帳號進度達到里程碑時授予勳章。遊戲可在飛行後、紀錄更新、登入或開啟日誌時檢查。

目前類別包括：

- 飛行時間里程碑。
- 生涯 XP 里程碑。
- 軍階進展。
- 空戰成果。
- 飛彈與機砲命中。
- 投彈。
- 機場降落表現與次數。
- 硬管空中加油表現與次數。

## 範例

- 完成首次有紀錄的出擊。
- 達到 10、50、100 或 500 飛行小時。
- 達到重要生涯 XP 里程碑。
- 晉升軍階。
- 首次空戰擊殺。
- 取得高降落分數。
- 完成硬管加油里程碑。

## 預留勳章系列

部分系列預留給尚未完整開放的活動，例如火箭攻擊、艦艇打擊、航艦降落或特殊精確打擊評分。

在對應玩法與評分流程啟用前，這些勳章可能保持鎖定。

## 勳章通知

解鎖時可能顯示簡短通知。若錯過，日誌可稍後補播待顯示的勳章通知。
