# 臂章

臂章是遊戲內收藏品。它不是認證資質，也不是獎牌；獲得後會作為帳號收藏保存。

在真實航空文化中，臂章會出現在飛行服、夾克、頭盔、裝備包、待命室和中隊牆上。它可能記錄中隊、部署、演習、共同笑話、職涯階段，或作為不同單位之間交換的紀念品。

在 Red Flag Sim 中，臂章屬於你的帳號收藏。獲得後，它會保存到你的飛行員收藏中，並可在日誌本或未來個人資料展示中出現。

臂章可能來自官方活動、模組相關獎勵、特別禮包、商店獎勵，以及未來社群或多人活動。若重複獲得同一臂章，系統可能保留額外數量，為未來交換和贈送功能留下空間。

未來方向包括資料相關展示、日誌本收藏、中隊主題臂章、限時活動臂章，以及好友系統開放後的好友互贈。
