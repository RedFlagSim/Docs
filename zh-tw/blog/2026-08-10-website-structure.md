# 網站架構調整說明

RedFlagSim 正在從單純文件站升級為完整官方網站。

Docs 仍承載操作指南、飛機模組和遊戲系統參考；新架構增加產品首頁、Dev Blog 和 Support，並將 About 作為獨立的產品介紹頁面。

文件仍是手冊、平台指南、機型模組與遊戲系統參考的集中入口。新的架構增加更清楚的產品入口、分組資源導航，以及專門發布開發更新的日誌。

## 為何調整

專案現在需要的不只是參考資料。隨著模擬器成長，網站也應介紹產品、呈現目前開發方向，並為版本說明與工程更新提供穩定位置。

## 主要變化

- Docs 成為官方網站中的一個模組。
- Dev Blog 用於發布開發動態與進度。
- Support 集中管理反饋、政策與官方社群管道。
- 視覺系統遵循 VitePress 版面規範並使用 RedFlagSim 紅色高亮。

导航圍繞文件、開發日誌、關於與支援組織。
