# F-15C “鷹”式制空戰鬥機

![F-15C 標題圖](/assets/F-15C/header.jpg)

本章介紹 Red Flag Sim 中 F-15C 的操縱界面、駕駛艙儀表、雷達、武器顯示和對抗系統。本文作為機型概覽，說明各系統的用途及相互關係；具體控件、符號和操作條件見對應章節。

本文檔以模擬器中的實現為對象，不替代真實飛機的飛行或維護手冊。尚未完成的功能列在文末的開發計劃中。

## 操縱與飛行狀態

飛行時需要結合空速、馬赫數、高度、姿態、迎角、過載和燃油狀態判斷飛機當前的工作狀態，而不能只看機頭指向。HUD 提供主要飛行參考，駕駛艙儀表用於補充和交叉檢查。

閱讀儀表時應注意單位：F-15C 的迎角標尺使用迎角單位，不是幾何角度；空速、馬赫數與過載也分別表示不同的飛行參數。具體讀法見[駕駛艙儀表](/zh-tw/Docs/aircraft/f15c/cockpit-instruments.html)和 [HUD 操作](/zh-tw/Docs/aircraft/f15c/hud-operation.html)。

觸控設備上的虛擬搖桿、油門、方向舵、傳感器控制及浮動 MFD 由觸控 UI 提供。控件位置和界面調整方法見[觸控 UI](/zh-tw/Docs/aircraft/f15c/touch-ui.html)。

## 雷達與目標信息

AN/APG-63 雷達的搜索和跟蹤信息顯示在 VSD（垂直態勢顯示器）上。主要工作模式包括遠距搜索（LRS）、邊掃描邊跟蹤（TWS）、單目標跟蹤（STT）和近距自動捕獲。

LRS 用於搜索目標，TWS 在掃描過程中維護目標航跡，STT 則集中跟蹤單個目標。距離標尺和天線俯仰共同決定當前查看和搜索的範圍；目標在距離範圍內，不代表它一定處於天線的高度覆蓋內。

雷達提供的目標信息也會用於 HUD 的目標框、距離和武器發射區顯示。搜索回波、目標航跡和 STT 跟蹤不是同一狀態，不能僅憑屏幕上出現目標符號就判斷武器已具備所需的跟蹤或制導支持。各模式的顯示和操作見 [AN/APG-63 雷達和 VSD](/zh-tw/Docs/aircraft/f15c/radar.html)。

## 武器與 HUD 顯示

F-15C 的武器顯示包括機炮、AIM-9、AIM-7 和 AIM-120 模式。不同模式共用部分符號，但瞄准信息來源和制導條件不同。

| 武器模式 | 主要顯示與區別 |
| --- | --- |
| 機炮 | 根據是否有雷達測距信息提供不同的瞄准參考，包括 GDS 准星和開炮後的 BATR 提示。 |
| AIM-9 | 顯示導引頭指向及 Cage / Uncage 狀態；雷達目標信息與紅外導引頭鎖定需要分別判斷。 |
| AIM-7 | 在本遊戲中要求 STT 下發射，發射後仍需雷達照射支持。 |
| AIM-120 | 包括有雷達目標信息時的發射提示，以及無 PDT 時的 VISUAL 目視模式。 |

有目標解算信息時，HUD 可顯示允許轉向誤差（ASE）圓、轉向點和動態發射區（DLZ）。DLZ 中的 RMax、RTR 與 RMin 是隨當前條件變化的射程參考，不是固定的導彈性能數值。進入射程或出現有利發射提示，也不等於必然命中。

完整的符號解釋、模式差異和限制見 [HUD 操作](/zh-tw/Docs/aircraft/f15c/hud-operation.html)。

## 告警與對抗系統

TEWS（戰術電子戰系統）顯示雷達告警和電子干擾狀態。其威脅符號用於判斷輻射源方位與優先級，符號距顯示器中心的距離不代表目標的實際距離。

雷達告警、電子干擾、箔條和紅外干擾彈各有不同用途。RWR 不能作為所有威脅的統一探測器，例如紅外導彈通常不會觸發雷達告警。符號、音調及對抗控制見[對抗系統](/zh-tw/Docs/aircraft/f15c/defensive-systems.html)。

## 文檔閱讀順序

初次使用本機型時，可先熟悉操縱與儀表，再閱讀傳感器和武器顯示：

1. [觸控 UI](/zh-tw/Docs/aircraft/f15c/touch-ui.html)：確認控件用途與佈局。
2. [駕駛艙儀表](/zh-tw/Docs/aircraft/f15c/cockpit-instruments.html)：熟悉飛行、發動機、燃油與武器狀態顯示。
3. [HUD 操作](/zh-tw/Docs/aircraft/f15c/hud-operation.html)：區分基本飛行符號與各武器模式。
4. [AN/APG-63 雷達和 VSD](/zh-tw/Docs/aircraft/f15c/radar.html)：理解搜索覆蓋、目標跟蹤和模式切換。
5. [對抗系統](/zh-tw/Docs/aircraft/f15c/defensive-systems.html)：識別告警信息及對抗狀態。

術語縮寫可查閱[附錄：縮略詞](/zh-tw/Docs/aircraft/f15c/appendix.html)。

## 開發計劃

以下 F-15C 功能計劃在未來版本中實現，當前版本尚未完成：

1. **冷艙啓動**：從完全斷電的飛機狀態開始，完成座艙準備、供電、發動機啓動、航電初始化和飛行前檢查後再進入滑行。
2. **地面服務**：在有效服務區域停機後，請求並管理加油、重新掛載、維修、外部電源以及其他地勤支援。
3. **彈射功能**：實現完整的緊急彈射流程，包括座艙蓋分離、彈射座椅啓動、降落傘展開和彈射後的飛行員狀態。
4. **無線電語音系統**：加入與僚機、預警機/GCI、空中交通管制和地勤之間的交互式語音通信，包括情境化呼叫、指令確認和戰術報告。
