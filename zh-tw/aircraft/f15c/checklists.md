# F-15C 操作檢查單

這些快速檢查單把手冊流程整理為座艙操作步驟，採用 DCS F-15C 手冊的默認鍵盤綁定，可按自己的操縱配置調整。

## 發動機啓動

1. 打開航行燈：`[Right Ctrl + L]`
2. 關閉座艙蓋：`[Left Ctrl + C]`
3. 啓動左發動機並將油門置於慢車：`[Right Alt + Home]`
4. 啓動右發動機並將油門置於慢車：`[Right Ctrl + Home]`
5. 檢查 RPM、FTIT、燃油流量和告警燈。

## 滑行與起飛

1. 確認 RPM 和 FTIT 穩定。
2. 小幅調整油門滑行。
3. 用方向舵/前輪轉向保持滑行路線。
4. 按需剎車：`[W]`
5. 起飛前放下襟翼：`[F]`
6. 對準跑道中線並停車。
7. 增至軍用推力或最大推力。
8. 約 100 節時平穩抬頭，建立 10 至 12 度俯仰。
9. 確認正爬升後收起起落架：`[G]`
10. 收起襟翼：`[F]`

## 導航

1. 選擇 NAV 模式：`[1]`
2. 切換航路點：`[Left Ctrl + ~]`
3. 跟隨 HUD 指引和 HSI 方位。
4. 交叉檢查距離和剩餘時間。
5. 持續監控高度、燃油和威脅狀態。

## 著陸

1. 選擇著陸/ILSN 航路點。
2. 放起落架前減速至 250 節以下。
3. 放下起落架：`[G]`
4. 放下襟翼：`[F]`
5. 最後進近穩定在約 180 節。
6. 保持 20 至 22 迎角單位。
7. 接地並收油門至慢車。
8. 保持約 13 度抬頭進行氣動剎車。
9. 低於約 90 節時放下機頭。
10. 按需使用機輪剎車：`[W]`

## AIM-120 AMRAAM

1. 打開雷達：`[I]`
2. 選擇 LRS 或 TWS：`[2]` 或 `[Right Ctrl + I]`
3. 選擇中程導彈：`[D]`
4. 將 TDC 移到目標上：`[;]`、`[,]`、`[.]`、`[/]`
5. 鎖定或指定目標：`[Enter]`
6. 確認距離、指引和身份。
7. 發射：`[Right Alt + Space]`
8. 戰術允許時，支持導彈直到主動制導。

## AIM-7 Sparrow

1. 打開雷達：`[I]`
2. 選擇 LRS：`[2]`
3. 用武器選擇切換到 AIM-7：`[D]`
4. 將目標鎖定在 STT：`[Enter]`
5. 確認有效距離和 ASE 指引。
6. 發射：`[Right Alt + Space]`
7. 保持雷達鎖定直到命中。

## AIM-9 Sidewinder

1. 按需選擇 ACM 模式：`[3]` 為垂直掃描，`[4]` 為孔徑模式。
2. 用武器選擇切換到 AIM-9：`[D]`
3. 將目標置於導引頭視場內。
4. 按需鎖定/解鎖導引頭：`[6]`
5. 等待導引頭提示音並確認有效距離。
6. 發射：`[Right Alt + Space]`

## M61 機炮

1. 選擇機炮：`[C]`
2. 可用時使用雷達鎖定或 AACQ。
3. 將目標置於計算瞄准具或漏斗內。
4. 短點射：`[Space]`
5. 重新評估接近率，避免衝過頭。
