# F-15C 防禦系統

F-15C 的防禦設備結合主動電子對抗、被動雷達告警，以及干擾絲與熱焰彈。飛行員需要理解威脅顯示、決定是否使用干擾，並在機動時施放合適的對抗措施。

<a id="rwr"></a>

## 戰術電子戰系統（TEWS）

TEWS 使用 AN/ALR-56C 雷達告警接收機，偵測來自飛機、艦船與地面系統的雷達訊號。接收機以被動方式運作，不會透過發射訊號暴露 F-15C。

TEWS 顯示以本機符號為中心。訊號的角度表示相對於本機的方位。<strong>訊號到中心的距離代表威脅程度，而非實際距離。</strong>

### 3. 三級威脅程度

<a :href="rwrThreatImage" target="_blank" rel="noopener">
  <img :src="rwrThreatImage" alt="TEWS 圖 3：最內圈為鎖定威脅，中間圈左側為尚未鎖定的新訊號 11，最外圈為搜尋訊號" loading="lazy" />
</a>

TEWS 依威脅程度，將訊號由內至外分為三個區域：

| 顯示區域 | 威脅程度 | 範例 |
| --- | --- | --- |
| 最內圈 | 高 | 鎖定本機的雷達、飛彈及其他高優先威脅。 |
| 中間圈 | 中 | 已偵測到、但尚未鎖定本機的火控雷達。 |
| 最外圈 | 低 | 威脅最低的訊號，例如本例中的搜尋雷達。 |

圖 3 左側新出現的 `11` 上方帶有半圓，表示這是新訊號。該火控雷達尚未鎖定本機，因此被歸類為中等威脅，顯示在中間圈。

<strong>符號越靠近中心，代表威脅越高，不代表訊號來源實際上越近。</strong> 請結合方位、雷達類型與鎖定標記判斷威脅。

<a id="rwr-audio"></a>

### 4. 聲音告警

TEWS 以不同聲音區分掃描、新訊號、鎖定與飛彈發射：

| 事件 | 聲音提示 | 對應顯示 |
| --- | --- | --- |
| 雷達掃描到本機 | 一聲掃描音。 | 對應的雷達訊號。 |
| 出現新訊號 | 特定、略高頻的提示音重複 3 次。 | 訊號上方出現半圓。 |
| 火控雷達鎖定本機 | 連續重複的掃描音。 | 訊號周圍出現完整圓圈。 |
| 敵方向本機發射雷達導引飛彈 | 4 聲急促、高頻的飛彈發射告警音。 | 對應訊號的圓圈同時閃爍。 |

## 干擾絲與熱焰彈

干擾絲用於對抗雷達導引威脅，熱焰彈則用於對抗紅外線威脅。座艙指示燈會在施放期間閃爍，並在剩餘數量偏低時發出警告。

對抗措施搭配機動使用時最有效：

1. 轉向，讓飛彈難以維持有利的提前追蹤路徑。
2. 對抗雷達導引飛彈時，在橫切或缺口機動中施放干擾絲。
3. 懷疑有紅外線飛彈時，改變機體朝向與熱訊號，並施放熱焰彈。
4. 施放後避免可預測的直線飛行。
5. 第一次防禦轉向後重新檢查 TEWS，不要直接認定威脅已解除。
