# F-15C 駕駛艙儀表

F-15C 座艙以 HUD、垂直態勢顯示器（VSD）與戰術電子戰系統（TEWS）顯示器為三個戰鬥參考。發動機、導航、燃油、武器與對抗儀表配置在其周圍及下方，讓飛行員專注戰鬥時仍能交叉檢查飛機狀態。

## 戰鬥顯示器

<a id="instrument-3"></a>

### 垂直態勢顯示器（VSD）

VSD 是 F-15C 的雷達顯示器，呈現搜尋空域、目標回波、鎖定狀態及超視距作戰所需目標細節。操作與符號見雷達章節。

![垂直態勢顯示器（VSD）](/assets/F-15C/Manual/fig-21-vsd.png)

<a id="instrument-9"></a>

### 戰術電子戰系統（TEWS）

TEWS 是雷達告警顯示器，在本機符號周圍呈現雷達輻射源，優先標示最危險的威脅，並顯示飛彈發射提示與電子干擾狀態。

![戰術電子戰系統（TEWS）](/assets/F-15C/Manual/fig-22-tews-display.png)

<a id="instrument-1"></a>

### 多用途彩色顯示器／武器控制面板

#### SIT 態勢顯示

SIT 以俯視方式呈現戰場，透過資料鏈顯示本機、友機與敵機。也能顯示多種地理圍欄、羅盤、Zulu 時間與牛眼座標。游標可隨動 VSD，也可解除隨動後獨立操作。

![SIT 態勢顯示](/assets/F-15C/Manual/fig-23-mpcd-sit-display.png)

#### AA 武器狀態面板

![AA 武器狀態面板](/assets/F-15C/Manual/fig-23-mpcd-weapons-panel.png)

AA 頁面顯示外掛油箱、武器類別、機炮彈藥及箔條和紅外干擾彈餘量。`FUEL` 表示已安裝油箱，`PYLON` 表示空掛架。武器選擇和完整顯示說明見 [MPCD 章節](/zh-tw/Docs/aircraft/f15c/mpcd.html)。

## 飛行儀表

<a id="instrument-12"></a>

### 起落架手柄

起落架手柄控制起落架放下與收起。

<a id="instrument-13"></a>

### 起落架位置指示器

指示器確認起落架已放下並鎖定。

<a id="instrument-2"></a>

### 指示空速與馬赫數

空速與馬赫數儀位於 MPCD 右側，固定刻度顯示 50 至 1000 節指示空速。約 200 節以上時馬赫指針才具有實用參考價值。

![指示空速與馬赫數](/assets/F-15C/Cockpit/indicated-airspeed-mach.png)

<a id="instrument-14"></a>

### 攻角指示器

攻角以 F-15 單位顯示，而非幾何角度。用於進場、低速機動與大攻角恢復。正常降落目標約為 20 至 22 單位。

![攻角指示器](/assets/F-15C/Manual/fig-25-aoa-indicator.png)

<a id="instrument-15"></a>

### 加速度計

顯示目前過載，並記錄本次出擊最大正、負過載。劇烈機動後可用於交叉檢查結構承受的負荷。

![加速度計](/assets/F-15C/Cockpit/accelerometer.png)

### 中央 ADI、HSI 與鄰近控制項

![中央 ADI、HSI 與鄰近控制項](/assets/F-15C/Cockpit/adi-hsi-emergency-jettison-steering-mode.png)

<a id="instrument-4"></a>

#### 姿態指引儀（ADI）

ADI 提供主要俯仰與坡度參考。旋轉球面俯仰刻度每 5 度一格，坡度每 10 度一格，每 30 度有較大標記。垂直與水平指令桿依所選導航來源提供引導，下方轉彎與側滑指示協助協調轉彎。儀表旁的選擇器可在功能可用時選擇 INS 或 AHRS 姿態來源。

<a id="instrument-16"></a>

#### 水平態勢指示器（HSI）

HSI 以平面圖呈現導航態勢。旋轉羅盤卡將本機航向置於頂部標記下方；航道箭頭與偏差桿顯示所選航道及橫向誤差。左上計數器顯示海里距離，右上顯示所選航道。COURSE SET 與 HEADING SET 旋鈕調整對應參考。ILS 進場時，航道偏差須搭配 ADI 與 HUD 引導使用。

<a id="instrument-22"></a>

#### 緊急拋棄按鈕

ADI 緊鄰左側有帶護罩的黃黑色 <strong>PUSH TO JETT</strong> 按鈕，可緊急拋棄符合條件的外掛物。僅在需要立即減輕負載時使用；實際拋棄項目依目前配置與任務規則而定。

<a id="instrument-23"></a>

#### 導航模式選擇器

緊急拋棄按鈕下方的選擇器，決定 HSI、ADI 與 HUD 引導資訊的導航來源：

- <strong>NAV：</strong>航線與導航點引導。
- <strong>TCN：</strong>TACAN 方位、距離與所選航道引導。
- <strong>ILS NAV：</strong>ILS 航向道、下滑道結合 NAV 引導。
- <strong>ILS TCN：</strong>ILS 結合 TACAN 引導。

<a id="instrument-17"></a>

### 機上時鐘

提供座艙時間參考，顯示 Zulu 時間，用於任務計時及導航交叉檢查。

![機上時鐘](/assets/F-15C/Cockpit/aircraft-clock.png)

### 高度表與垂直速度儀表

![高度表與垂直速度儀表](/assets/F-15C/Cockpit/altimeter-vvi.png)

<a id="instrument-6"></a>

#### 氣壓高度表

滾筒與指針以英尺顯示高度。滾筒給出主要數值，指針提供細部讀值。使用氣壓旋鈕設定所需當地高度表氣壓；設定錯誤會造成指示高度錯誤。

<a id="instrument-5"></a>

#### 垂直速度指示器（VVI）

VVI 以每分鐘千英尺顯示爬升或下降率。順時針為爬升，逆時針為下降。

## 發動機與燃油儀表

### 發動機轉速與溫度

![發動機轉速與溫度](/assets/F-15C/Cockpit/tachometer-ftit.png)

<a id="instrument-8"></a>

#### 轉速表

成對轉速表顯示左右發動機 0 至 110% 轉速。啟動、滑行、起飛檢查與油門交叉檢查時，應同時讀取指針與計數器。

<a id="instrument-7"></a>

#### 風扇渦輪入口溫度（FTIT）

成對 FTIT 表顯示 0 至 1400 °C 渦輪溫度。指針提供連續讀值，計數器方便確認。異常高值代表渦輪過熱，應立即注意。

### 燃油流量與排氣噴嘴位置

![燃油流量與排氣噴嘴位置](/assets/F-15C/Cockpit/fuel-flow-nozzle-position.png)

<a id="instrument-18"></a>

#### 發動機燃油流量

顯示供給發動機的總燃油流量，包含後燃器流量，單位為磅／小時。搭配油量顯示監控消耗，辨認發動機或燃油系統的異常行為。

<a id="instrument-19"></a>

#### 發動機噴嘴位置

噴嘴表以完全開啟為基準顯示開度百分比。開度會隨發動機功率與後燃器運作而改變。

### 液壓與發動機油壓

![液壓與發動機油壓](/assets/F-15C/Cockpit/hydraulic-oil-pressure.png)

<a id="instrument-24"></a>

#### 液壓壓力指示器

三個表顯示 <strong>PC1</strong>、<strong>PC2</strong> 與 <strong>UTIL</strong> 的 0 至 4000 psi 壓力。PC1、PC2 供應飛控，公用系統供應起落架、煞車、前輪轉向等設備。正常壓力約 3000 psi；明顯下降或歸零可協助辨認受影響的系統。

<a id="instrument-25"></a>

#### 發動機油壓指示器

下方兩表顯示左右發動機 0 至 100 psi 油壓。比較兩具發動機，並將低讀值與對應注意燈交叉檢查。

<a id="instrument-10"></a>

### 燃油量

指針以千磅顯示內部總油量。上方計數器顯示總燃油，下方 LEFT、RIGHT 計數器及選擇器用於查看個別油箱與檢查指示器。

![燃油量](/assets/F-15C/Cockpit/fuel-quantity.png)

## 壓力與對抗措施

<a id="instrument-20"></a>

### 座艙壓力表

顯示等效座艙高度。損壞或增壓失效使座艙高度接近 10000 英尺時，應立即下降。

![座艙壓力表](/assets/F-15C/Cockpit/cabin-pressure.png)

<a id="instrument-11"></a>

### 干擾絲與熱焰彈指示器

施放時指示燈閃爍約三秒。對抗措施剩餘數量極低時，最低餘量警告燈會亮起。

![干擾絲與熱焰彈指示器](/assets/F-15C/Cockpit/chaff-flare-indicators.png)

<a id="instrument-21"></a>

### 警告燈面板

顯示飛機各系統警告。
