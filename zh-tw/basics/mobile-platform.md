# 行動平台飛行手冊

本文適用於 iOS/Android 行動裝置。

## 核心規則：垂直持握

這是建立精確姿態控制的基本步驟：

![核心規則：垂直持握](/assets/tilt-guide.png)

- ❌ 錯誤：將手機水平平放。此時滾轉與偏航軸耦合，系統難以可靠區分滾轉輸入。
- ✅ 標準：雙手持握裝置，讓螢幕垂直於地面，正對自己。

### 為什麼必須垂直持握？

體感控制需要清楚區分滾轉軸。裝置平放時，姿態解算中的滾轉與偏航軸耦合，系統無法可靠辨別玩家是在滾轉還是偏航。因此，體感控制必須以直立持握為基準姿態。

## 操縱輸入

- 俯仰（升降舵）：將手機頂端向後、朝身體傾斜以拉起爬升；向前、遠離身體傾斜以壓低機頭俯衝。
- 滾轉（副翼）：像轉動方向盤一樣向左或向右旋轉手機。

## 觸控虛擬搖桿

行動版也支援螢幕上的虛擬搖桿，可取代體感操縱。希望保持裝置不動時，請在飛行前選擇虛擬搖桿操縱模式。

![觸控虛擬搖桿](/assets/mobile-virtual-stick.jpeg)

- 俯仰：向下拖曳搖桿以拉起，向上拖曳以壓低機頭。
- 滾轉：向左或向右拖曳，控制對應方向的滾轉。
- 回中：放開搖桿後會自動回到中央。

垂直持握與校準要求只適用於體感控制。使用觸控虛擬搖桿時，可採用任何舒適的觀看姿勢。

## 飛行前設定與精確操縱

1. 建立基準（校準）：進入座艙後或起飛前，採取舒適坐姿，將裝置穩定直立，開啟主選單並點選 Calibrate Gyro。系統會將目前角度記錄為中立零點。

    ![飛行前設定與精確操縱](/assets/mobile-gyro-calibration.jpeg)

2. 穩定操縱：密集編隊、空中加油或近距離纏鬥時，將手肘支撐在膝蓋或扶手上，過濾身體顫動，達到小於一度的操縱精度。

## 觸控 UI 編輯模式

快速連續點擊螢幕空白處四次，即可開啟觸控 UI 編輯模式，也可在主選單選擇 `UI Editor`。

![觸控 UI 編輯模式](/assets/mobile-ui-editor.jpeg)

在編輯模式中可以：

- 重新排列控制項：選取並移動控制項，自訂螢幕配置。
- 進入透明模式：使用 `CLEAR MODE` 切換為透明呈現。
- 調整整體不透明度：降低觸控 UI 對飛行視野的遮擋。
- 設定浮動 MFD：調整浮動多功能顯示器的大小與可見性。控制項與編輯面板詳見 [F-15C 觸控 UI 文件](/zh-tw/Docs/aircraft/f15c/touch-ui.html#item-3)。
