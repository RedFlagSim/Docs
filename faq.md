# FAQ

## What is the current project stage?

Red Flag Sim is under active development. Systems and documentation are updated continuously.

## Is F-15C the only module right now?

F-15C is currently the first playable core module. Additional modules are in development.

## Will systems change between versions?

Yes. As simulation fidelity improves, system behavior and workflows may be refined.

## How are localization updates handled?

English is the source language. Localized pages are updated in parallel and validated by i18n parity checks in CI.
