# Website Restructure Notes

Red Flag Sim is moving from a documentation-only site toward a complete official website.

The Docs section remains the place for manuals, platform guides, aircraft modules, and game-system references. The new site structure adds a clearer product-level entry point, grouped resource navigation, and a dedicated Dev Blog for development updates.

## Why This Change

The project now needs more than reference material. As the simulator grows, the website should also explain the product, surface current development direction, and provide a stable place for release notes and engineering updates.

## What Changes

- Docs become one module within the official website.
- Dev Blog becomes the home for development notes and progress updates.
- Navigation is organized around Docs, Dev Blog, About, and Support.
- The visual system follows VitePress conventions with a RedFlagSim red accent.
