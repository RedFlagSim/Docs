| --- | --- |

| AoA | Anstellwinkel |
| ARH | Aktive Radarzielsuche |
| ASE | Zulässiger Steuerfehler |
| ATC | Flugsicherung |
| AWACS | Luftgestütztes Frühwarn- und Führungssystem |
| BFM | Grundlegende Jagdflugmanöver |
| BORE | Boresight-Erfassungsmodus |
| BVR | Außerhalb der Sichtweite |
| CAS | Steuerungsunterstützungssystem |
| DCS | Digital Combat Simulator |
| ECM | Elektronische Gegenmaßnahmen |
| EOS | Elektrooptisches System |
| EW | Elektronische Kampfführung |
| FC | Feuerleitung |
| FPM | Flugwegmarkierung |
| FTIT | Fan-Turbineneintrittstemperatur |
| GCI | Bodengeführtes Abfangen |
| GDS | Feuerleitvisier der Bordkanone |
| GS | Geschwindigkeit über Grund |
| HOJ | Zielsuchverfahren auf Störsender |

| MRM | Mittelstreckenrakete |
| NCTR | Nichtkooperative Zielerkennung |
| PRF | Pulswiederholfrequenz |
| RALT | Radarhöhe |
| RCS | Radarrückstrahlfläche |
| RWR | Radarwarnempfänger |
| SARH | Halbaktive Radarzielsuche |
| SAM | Boden-Luft-Rakete |
| SRM | Kurzstreckenrakete |
