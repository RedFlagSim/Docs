# F-15C-Funkverkehr

Funk verbindet die F-15C mit Schwarm, AWACS/GCI, Flugsicherung und Bodenpersonal. Meldungen nennen Empfänger, gewünschte Aktion und die nötigen taktischen Informationen.

## Aufbau der Meldungen

1. Rufzeichen: Empfänger und Sender, beispielsweise `Chevy 22, Chevy 21`.
2. Befehl oder Bericht: Aktion oder Zustand, etwa `engage bandits` oder `missile launch`.
3. Details: Peilung, Entfernung, Höhe, Zielart, Uhrzeitrichtung oder Ergebnis.

Kurz und präzise funken. Im Kampf ist auch Funkzeit eine Ressource.

## Schwarm- und Flügelmannbefehle

| Befehlsgruppe | Zweck |
| --- | --- |
| Engage my target | Vom Spieler bezeichnetes Ziel angreifen |
| Engage bandits | Luftziele suchen und angreifen |
| Cover me | Unmittelbarste Bedrohung des Spielers bekämpfen |
| Rejoin | Zur Formation zurückkehren |
| Go to route / RTB | Route fortsetzen oder zur Basis zurückkehren |
| Radar on/off | Radaremissionen des Flügelmanns steuern |
| ECM on/off | Störsender steuern |
| Smoke on/off | Sichtidentifikation oder Kunstflugrauch |
| Formation commands | Abstände und Formation ändern |

Flügelmänner bestätigen meist mit `Copy`, `Roger` oder `Affirm`. Ist die Ausführung nicht möglich, folgen `Negative` oder `Unable`.

## AWACS- und GCI-Anfragen

Luft- oder Bodenkontrolle kann das Lagebild liefern, wenn dein Radar schweigt, gestört wird oder anderswo sucht.

| Anfrage | Rückmeldung |
| --- | --- |
| Bogey dope | Peilung, Entfernung, Höhe und Aspekt des nächsten feindlichen oder unbekannten Flugzeugs |
| Picture | Zusammenfassung erkannter Gruppen im Gebiet |
| Vector to home plate | Peilung und Entfernung zur nächsten geeigneten freundlichen Basis |
| Vector to tanker | Peilung und Entfernung zum nächsten freundlichen Tanker |

Berichte hängen von Sensorabdeckung und Wissen der Koalition ab. Weiter mit Radar, TEWS und Sichtkontrolle prüfen.

## Flugsicherung

ATC dient Bodenbewegung, Start, Anflug und Landung. Häufige Anfragen:

- Rollfreigabe
- Startfreigabe
- Rückkehr- oder Anfluganfrage
- Landefreigabe
- Durchstart- oder Staffelungsanweisungen

Im Anflug können Bahn, Kurs, Verkehrsabstände und Gleitpfadkorrekturen gemeldet werden.

## Bodenpersonal

Befehle sind beim Parken auf einem gültigen Flugplatz oder Servicebereich verfügbar. Je nach Mission sind Betankung, Wiederbewaffnung, Reparatur und Beladungsänderung möglich.

## Meldungen anderer Einheiten

| Quelle | Beispielbedeutung |
| --- | --- |
| Flügelmann | Startlauf, Fahrwerk eingefahren, Wiederanschluss, Angriff, Abwehr, Rückkehr |
| Waffenmeldungen des Flügelmanns | `Fox One`, `Fox Two`, `Fox Three`, `Guns`, `Winchester` |
| Bedrohungsmeldungen | Radaraufschaltung, Bodenradaraufschaltung, Raketenstart, SAM-Start |
| AWACS/GCI | Feindlage, Nahbegegnungswarnung, keine Kontakte, Vektoren |
| ATC | Rollen, Start, Landung, Warteschleife, Gleitpfadkorrektur |

## Sprachwarnsystem

Das oft Betty genannte Sprachwarnsystem der F-15C meldet dringende Flugzeugzustände und Fehler.

| Auslöser | Sprachmeldung |
| --- | --- |
| Rechter Triebwerksbrand | `Engine fire right` |
| Linker Triebwerksbrand | `Engine fire left` |
| Beschädigte Flugsteuerung | `Flight controls` |
| Fahrwerk über sicherer Geschwindigkeit ausgefahren | `Gear down` |
| Fahrwerk im ILS-Anflug nicht ausgefahren | `Gear up` |
| Bingo-Kraftstoffschwelle erreicht | `Bingo fuel` |
| Niedriger Kraftstoffstand | `Fuel 1500`, `Fuel 800`, `Fuel 500` |
| Autopilot-/Steuerungsausfall | `ACS failure` |
| Navigationsrechnerausfall | `NCS failure` |
| ECM-Ausfall | `ECM failure` |
| Hydraulikausfall | `Hydraulics failure` |
| Radarausfall | `Radar failure` |
| Maximale G überschritten | `Maximum G` |
| Maximaler Anstellwinkel überschritten | `Maximum angle of attack` |
| Kritische Geschwindigkeit | `Critical speed` |
| Raketenwarnung | `Missile` gefolgt von Uhrzeitrichtung und Hoch-/Tiefangabe. |

Behandle Warnungen vorrangig. Bedrohung oder Fehler erkennen, zuerst fliegen, dann Konfiguration korrigieren oder abwehren.
