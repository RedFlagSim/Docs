# Hinweise zur neuen Website-Struktur

RedFlagSim wird von einer reinen Dokumentationsseite zu einer vollständigen offiziellen Website erweitert.

Docs bleibt der Bereich für Anleitungen, Flugzeugmodule und Spielsysteme. Die neue Struktur ergänzt Dev Blog, Support und eine eigenständige About-Seite.

## Wichtigste Änderungen

- Docs ist ein Modul innerhalb der offiziellen Website.
- Dev Blog bündelt Entwicklungsnotizen und Fortschritt.
- Support enthält Feedback, Richtlinien und offizielle Kanäle.
- Das Design folgt VitePress-Konventionen mit rotem RedFlagSim-Akzent.
