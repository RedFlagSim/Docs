# Homepage Screenshots

Add new gallery images to this directory. The homepage discovers them automatically at dev-server startup and build time.

- Supported formats: PNG, JPG, JPEG, and WebP.
- Images are sorted by filename. Use prefixes such as `01-`, `02-`, and `03-` to control their order.
- Do not place gallery images inside the `thumbnails` directory.
- An optional optimized thumbnail can be placed in `thumbnails` with the same filename stem. Without one, the full image is used as its thumbnail.

Restart the local preview if a newly added file does not appear immediately.
