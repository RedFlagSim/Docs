# F-15C 操作检查单

这些快速检查单把手册流程整理为座舱操作步骤，采用 DCS F-15C 手册的默认键盘绑定，可按自己的操纵配置调整。

## 发动机启动

1. 打开航行灯：`[Right Ctrl + L]`
2. 关闭座舱盖：`[Left Ctrl + C]`
3. 启动左发动机并将油门置于慢车：`[Right Alt + Home]`
4. 启动右发动机并将油门置于慢车：`[Right Ctrl + Home]`
5. 检查 RPM、FTIT、燃油流量和告警灯。

## 滑行与起飞

1. 确认 RPM 和 FTIT 稳定。
2. 小幅调整油门滑行。
3. 用方向舵/前轮转向保持滑行路线。
4. 按需刹车：`[W]`
5. 起飞前放下襟翼：`[F]`
6. 对准跑道中线并停车。
7. 增至军用推力或最大推力。
8. 约 100 节时平稳抬头，建立 10 至 12 度俯仰。
9. 确认正爬升后收起起落架：`[G]`
10. 收起襟翼：`[F]`

## 导航

1. 选择 NAV 模式：`[1]`
2. 切换航路点：`[Left Ctrl + ~]`
3. 跟随 HUD 指引和 HSI 方位。
4. 交叉检查距离和剩余时间。
5. 持续监控高度、燃油和威胁状态。

## 着陆

1. 选择着陆/ILSN 航路点。
2. 放起落架前减速至 250 节以下。
3. 放下起落架：`[G]`
4. 放下襟翼：`[F]`
5. 最后进近稳定在约 180 节。
6. 保持 20 至 22 迎角单位。
7. 接地并收油门至慢车。
8. 保持约 13 度抬头进行气动刹车。
9. 低于约 90 节时放下机头。
10. 按需使用机轮刹车：`[W]`

## AIM-120 AMRAAM

1. 打开雷达：`[I]`
2. 选择 LRS 或 TWS：`[2]` 或 `[Right Ctrl + I]`
3. 选择中程导弹：`[D]`
4. 将 TDC 移到目标上：`[;]`、`[,]`、`[.]`、`[/]`
5. 锁定或指定目标：`[Enter]`
6. 确认距离、指引和身份。
7. 发射：`[Right Alt + Space]`
8. 战术允许时，支持导弹直到主动制导。

## AIM-7 Sparrow

1. 打开雷达：`[I]`
2. 选择 LRS：`[2]`
3. 用武器选择切换到 AIM-7：`[D]`
4. 将目标锁定在 STT：`[Enter]`
5. 确认有效距离和 ASE 指引。
6. 发射：`[Right Alt + Space]`
7. 保持雷达锁定直到命中。

## AIM-9 Sidewinder

1. 按需选择 ACM 模式：`[3]` 为垂直扫描，`[4]` 为孔径模式。
2. 用武器选择切换到 AIM-9：`[D]`
3. 将目标置于导引头视场内。
4. 按需锁定/解锁导引头：`[6]`
5. 等待导引头提示音并确认有效距离。
6. 发射：`[Right Alt + Space]`

## M61 机炮

1. 选择机炮：`[C]`
2. 可用时使用雷达锁定或 AACQ。
3. 将目标置于计算瞄准具或漏斗内。
4. 短点射：`[Space]`
5. 重新评估接近率，避免冲过头。
