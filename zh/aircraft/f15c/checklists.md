# F-15C 操作检查单

以下检查单根据手册流程整理，默认使用 DCS F-15C 的常见键位，可按自己的控制设置调整。

## 开车

1. 打开导航灯：`[Right Ctrl + L]`
2. 关闭座舱盖：`[Left Ctrl + C]`
3. 启动左发并置慢车：`[Right Alt + Home]`
4. 启动右发并置慢车：`[Right Ctrl + Home]`
5. 检查转速、FTIT、燃油流量和告警灯。

## 滑行和起飞

1. 检查发动机仪表稳定。
2. 小油门开始滑行。
3. 用方向舵/前轮转向保持滑行路线。
4. 必要时刹车：`[W]`
5. 起飞前放襟翼：`[F]`
6. 对准跑道中线并停稳。
7. 推到军推或最大推力。
8. 约 100 节平滑抬头，建立 10 到 12 度仰角。
9. 正爬升后收起落架：`[G]`
10. 收襟翼：`[F]`

## 导航

1. 选择 NAV 模式：`[1]`
2. 切换航路点：`[Left Ctrl + ~]`
3. 按 HUD 和 HSI 指引飞行。
4. 交叉检查距离和预计时间。
5. 持续关注高度、燃油和威胁状态。

## 着陆

1. 选择目的机场/ILSN 航点。
2. 低于 250 节后放起落架。
3. 起落架放下：`[G]`
4. 襟翼放下：`[F]`
5. 最终进近稳定在约 180 节。
6. 保持 20 到 22 迎角单位。
7. 接地后收油至慢车。
8. 保持约 13 度抬头气动刹车。
9. 低于约 90 节放下前轮。
10. 必要时轮刹：`[W]`

## AIM-120 AMRAAM

1. 开雷达：`[I]`
2. 选择 LRS 或 TWS：`[2]` 或 `[Right Ctrl + I]`
3. 选择中距导弹：`[D]`
4. 移动 TDC 到目标：`[;]`、`[,]`、`[.]`、`[/]`
5. 锁定或指定目标：`[Enter]`
6. 确认距离、发射提示和识别。
7. 发射：`[Right Alt + Space]`
8. 战术允许时支持到主动。

## AIM-7 Sparrow

1. 开雷达：`[I]`
2. 选择 LRS：`[2]`
3. 选择 AIM-7：`[D]`
4. STT 锁定目标：`[Enter]`
5. 确认距离和 ASE 指引。
6. 发射：`[Right Alt + Space]`
7. 保持锁定直到命中。

## AIM-9 Sidewinder

1. 需要时选择 ACM：`[3]` 垂直扫描或 `[4]` 孔径。
2. 选择 AIM-9：`[D]`
3. 将目标置于导引头视场。
4. 必要时囚笼/非囚笼：`[6]`
5. 等待导引头音调和有效射程。
6. 发射：`[Right Alt + Space]`

## M61 机炮

1. 选择机炮：`[C]`
2. 尽量使用雷达锁定或自动锁定。
3. 将目标置于计算瞄准或漏斗内。
4. 短点射：`[Space]`
5. 重新评估闭合率，避免冲过头。
