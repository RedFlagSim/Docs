# F-15C 对抗系统

F-15C 的生存能力来自主动电子干扰、被动雷达告警以及箔条/红外干扰弹。飞行员需要理解 TEWS 的威胁信息，判断是否开干扰，并在机动中投放正确对抗措施。

<a id="rwr"></a>

## 战术电子战系统（TEWS）

TEWS 通过 AN/ALR-56C 雷达告警接收机被动探测飞机、舰船和地面系统的雷达信号。接收机本身不发射，因此不会因发射信号暴露 F-15C。

TEWS 圆形显示器以本机符号为中心，信号在圆周方向上的位置表示其相对本机的方位；**信号到中心的距离表示威胁等级，不代表真实距离。**

### 3. 三层威胁分级

<a :href="rwrThreatImage" target="_blank" rel="noopener">
  <img :src="rwrThreatImage" alt="TEWS 图 3：锁定信号位于内层，左侧新出现但尚未锁定本机的 11 位于中层，搜索信号位于外层" loading="lazy" />
</a>

TEWS 按威胁等级将信号分为三圈，从内到外排列：

| 显示区域 | 威胁等级 | 示例 |
| --- | --- | --- |
| 最内圈 | 高 | 正在锁定本机的雷达、导弹等。 |
| 中间圈 | 中 | 已探测到但尚未锁定本机的火控雷达。 |
| 最外圈 | 低 | 威胁最低的信号，例如图中的搜索雷达。 |

图 3 左侧新出现的 `11` 上方带有半圆，表示这是一个新信号。这个火控雷达尚未锁定本机，因此被归入中等威胁，显示在中间圈。

**越靠近中心表示威胁等级越高，而不是发射源离本机越近。** 读取 TEWS 时，应结合方位、信号类别和锁定标记判断当前威胁。

<a id="rwr-audio"></a>

### 4. 声音告警

TEWS 会用不同的声音提示扫描、新信号、锁定和导弹发射：

| 事件 | 声音提示 | 对应显示 |
| --- | --- | --- |
| 雷达扫描到本机 | 一声单音扫描音。 | 对应的雷达信号。 |
| 出现新信号 | 特定的略高频提示音，重复 3 次。 | 信号上方出现半圆。 |
| 火控雷达锁定本机 | 连续重复的扫描音。 | 信号外出现完整圆圈。 |
| 对方向本机发射雷达制导导弹 | 4 声急促的高频导弹发射告警音。 | 对应信号的圆圈同时闪烁。 |

## 箔条和红外干扰弹

箔条用于对抗雷达制导威胁，红外干扰弹用于对抗热寻的威胁。投放期间座舱指示灯闪烁，余量较低时会给出提示。投放必须和机动结合：

1. 通过转向破坏导弹提前量。
2. 对雷达导弹使用箔条并执行横切/缺口机动。
3. 对红外导弹使用热焰弹并改变热源角度。
4. 投放后不要保持直线飞行。
5. 防御后重新检查 TEWS，不要默认威胁已解除。
