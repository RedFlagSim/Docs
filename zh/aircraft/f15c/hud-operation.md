# F-15C HUD 操作

HUD 是 F-15C 最重要的飞行与武器显示。它把姿态、导航、空速、高度、目标和武器信息投射到飞行员正前方，让飞行员在机动和交战中减少低头看仪表的时间。

## 基本符号

许多 HUD 符号在不同模式中都会保留。

![图 38. F-15C HUD 基本符号](/assets/F-15C/Manual/fig-38-hud-basic-symbology.png)

| 符号 | 含义 |
| --- | --- |
| 航向标尺 | 当前磁航向和航向参考 |
| 坡度参考 | 显示飞机坡度 |
| 空速标尺 | 指示空速，单位为节 |
| 高度标尺 | 通常显示气压高度 |
| 速度矢量 | 飞机真实飞行路径 |
| 飞机基准 | 机体纵轴参考 |
| 机炮十字 | 与 M61 机炮轴线相关的固定参考 |
| 俯仰标尺 | 以 5 度为单位显示俯仰姿态 |
| 过载读数 | 当前过载和最大记录过载 |

## 导航模式

### NAV 模式

NAV 模式为选定航路点提供航向、距离和预计时间。

![图 39. HUD 导航模式](/assets/F-15C/Manual/fig-39-hud-navigation-mode.png)

右下角会显示当前航路点和模式，例如 `1NAV`；距离以海里显示，例如 `N 42.1`；下方显示按当前速度估算的到达时间。

### 仪表着陆导航

ILSN 模式在普通导航信息基础上增加进近和下滑参考。

![图 40. HUD 着陆模式](/assets/F-15C/Manual/fig-40-hud-landing-mode.png)

进近时应让速度矢量稳定在着陆引导参考内。低高度时高度显示会切换到无线电高度参考。迎角框用于保持正确着陆迎角，不要只盯俯仰角。

## 机炮模式

### 无雷达锁定机炮

无雷达锁定时选择 M61 机炮，HUD 会显示固定瞄准参考和机炮弹药余量。

![图 41. 无雷达锁定机炮模式](/assets/F-15C/Manual/fig-41-gun-no-lock-mode.png)

该模式适合雷达测距不可用时作为备用。应短点射并根据弹道修正。

### 机炮指引瞄准

雷达锁定目标并选择机炮后，HUD 进入 GDS 模式。

![图 42. 机炮 GDS 模式](/assets/F-15C/Manual/fig-42-gun-gds-mode.png)

GDS 会显示目标指示框、计算瞄准提示、目标距离/闭合率，以及当前武器、弹药、本机马赫数和目标马赫数等信息。

## AIM-9 响尾蛇模式

AIM-9 为红外制导导弹，不需要发射后雷达照射。

![图 43. AIM-9 囚笼模式](/assets/F-15C/Manual/fig-43-aim9-caged-mode.png)

囚笼模式将导引头限制在机头附近，适合在密集编队中选择具体目标。

![图 44. AIM-9 非囚笼/扫描模式](/assets/F-15C/Manual/fig-44-aim9-uncaged-scan-mode.png)

非囚笼模式下，大圆表示导引头视场，小圆表示当前导引头指向。锁定热源后，小圆会跟随目标。

![图 45. AIM-9 雷达协助模式](/assets/F-15C/Manual/fig-45-aim9-radar-slaved-mode.png)

有雷达锁定时，AIM-9 导引头可被引向雷达目标。导弹仍依靠红外制导，但雷达测距能帮助判断是否适合发射。

## AIM-7 麻雀模式

AIM-7 是半主动雷达制导导弹，必须由本机雷达持续照射目标直到命中。

![图 46. AIM-7 泛指模式](/assets/F-15C/Manual/fig-46-aim7-flood-mode.png)

泛指模式适合近距、无法正常锁定时使用。目标必须在整个导弹飞行过程中保持在泛指圆内。

![图 47. AIM-7 STT 模式](/assets/F-15C/Manual/fig-47-aim7-stt-mode.png)

STT 模式会显示目标指示框、ASE 圆、目标距离标尺、目标方位/航向信息以及允许发射提示。发射后必须保持雷达锁定。

## AIM-120 AMRAAM 模式

AIM-120 可以接受本机中段支持，随后使用自身主动雷达导引头制导。

![图 48. AIM-120 目视模式](/assets/F-15C/Manual/fig-48-aim120-visual-mode.png)

目视模式适合近距已目视确认目标时使用，导弹会在导引头视场内搜索目标。

![图 49. AIM-120 STT 发射前](/assets/F-15C/Manual/fig-49-aim120-stt-before-launch.png)

![图 50. AIM-120 STT 发射后](/assets/F-15C/Manual/fig-50-aim120-stt-after-launch.png)

发射后 HUD 会显示导弹主动时间和预计命中时间等提示。战术允许时应支持到导弹主动。

## 自动锁定模式

近距格斗中可以使用自动锁定模式快速捕获目标。

![图 51. 孔径自动锁定模式](/assets/F-15C/Manual/fig-51-aacq-boresight-mode.png)

孔径模式在机头前方窄范围内捕获第一个有效目标。

![图 52. 垂直扫描自动锁定模式](/assets/F-15C/Manual/fig-52-aacq-vertical-scan-mode.png)

垂直扫描模式搜索机头上方的狭长区域，适合目标穿越升力矢量时使用。
