# F-15C “鹰”式制空战斗机

![F-15C 标题图](/assets/F-15C/header.jpg)

本章介绍 Red Flag Sim 中 F-15C 的操纵界面、驾驶舱仪表、雷达、武器显示和对抗系统。本文作为机型概览，说明各系统的用途及相互关系；具体控件、符号和操作条件见对应章节。

本文档以模拟器中的实现为对象，不替代真实飞机的飞行或维护手册。尚未完成的功能列在文末的开发计划中。

## 操纵与飞行状态

飞行时需要结合空速、马赫数、高度、姿态、迎角、过载和燃油状态判断飞机当前的工作状态，而不能只看机头指向。HUD 提供主要飞行参考，驾驶舱仪表用于补充和交叉检查。

阅读仪表时应注意单位：F-15C 的迎角标尺使用迎角单位，不是几何角度；空速、马赫数与过载也分别表示不同的飞行参数。具体读法见[驾驶舱仪表](/zh/Docs/aircraft/f15c/cockpit-instruments.html)和 [HUD 操作](/zh/Docs/aircraft/f15c/hud-operation.html)。

触控设备上的虚拟摇杆、油门、方向舵、传感器控制及浮动 MFD 由触控 UI 提供。控件位置和界面调整方法见[触控 UI](/zh/Docs/aircraft/f15c/touch-ui.html)。

## 雷达与目标信息

AN/APG-63 雷达的搜索和跟踪信息显示在 VSD（垂直态势显示器）上。主要工作模式包括远距搜索（LRS）、边扫描边跟踪（TWS）、单目标跟踪（STT）和近距自动捕获。

LRS 用于搜索目标，TWS 在扫描过程中维护目标航迹，STT 则集中跟踪单个目标。距离标尺和天线俯仰共同决定当前查看和搜索的范围；目标在距离范围内，不代表它一定处于天线的高度覆盖内。

雷达提供的目标信息也会用于 HUD 的目标框、距离和武器发射区显示。搜索回波、目标航迹和 STT 跟踪不是同一状态，不能仅凭屏幕上出现目标符号就判断武器已具备所需的跟踪或制导支持。各模式的显示和操作见 [AN/APG-63 雷达和 VSD](/zh/Docs/aircraft/f15c/radar.html)。

## 武器与 HUD 显示

F-15C 的武器显示包括机炮、AIM-9、AIM-7 和 AIM-120 模式。不同模式共用部分符号，但瞄准信息来源和制导条件不同。

| 武器模式 | 主要显示与区别 |
| --- | --- |
| 机炮 | 根据是否有雷达测距信息提供不同的瞄准参考，包括 GDS 准星和开炮后的 BATR 提示。 |
| AIM-9 | 显示导引头指向及 Cage / Uncage 状态；雷达目标信息与红外导引头锁定需要分别判断。 |
| AIM-7 | 在本游戏中要求 STT 下发射，发射后仍需雷达照射支持。 |
| AIM-120 | 包括有雷达目标信息时的发射提示，以及无 PDT 时的 VISUAL 目视模式。 |

有目标解算信息时，HUD 可显示允许转向误差（ASE）圆、转向点和动态发射区（DLZ）。DLZ 中的 RMax、RTR 与 RMin 是随当前条件变化的射程参考，不是固定的导弹性能数值。进入射程或出现有利发射提示，也不等于必然命中。

完整的符号解释、模式差异和限制见 [HUD 操作](/zh/Docs/aircraft/f15c/hud-operation.html)。

## 告警与对抗系统

TEWS（战术电子战系统）显示雷达告警和电子干扰状态。其威胁符号用于判断辐射源方位与优先级，符号距显示器中心的距离不代表目标的实际距离。

雷达告警、电子干扰、箔条和红外干扰弹各有不同用途。RWR 不能作为所有威胁的统一探测器，例如红外导弹通常不会触发雷达告警。符号、音调及对抗控制见[对抗系统](/zh/Docs/aircraft/f15c/defensive-systems.html)。

## 文档阅读顺序

初次使用本机型时，可先熟悉操纵与仪表，再阅读传感器和武器显示：

1. [触控 UI](/zh/Docs/aircraft/f15c/touch-ui.html)：确认控件用途与布局。
2. [驾驶舱仪表](/zh/Docs/aircraft/f15c/cockpit-instruments.html)：熟悉飞行、发动机、燃油与武器状态显示。
3. [HUD 操作](/zh/Docs/aircraft/f15c/hud-operation.html)：区分基本飞行符号与各武器模式。
4. [AN/APG-63 雷达和 VSD](/zh/Docs/aircraft/f15c/radar.html)：理解搜索覆盖、目标跟踪和模式切换。
5. [对抗系统](/zh/Docs/aircraft/f15c/defensive-systems.html)：识别告警信息及对抗状态。

术语缩写可查阅[附录：缩略词](/zh/Docs/aircraft/f15c/appendix.html)。

## 开发计划

以下 F-15C 功能计划在未来版本中实现，当前版本尚未完成：

1. **冷舱启动**：从完全断电的飞机状态开始，完成座舱准备、供电、发动机启动、航电初始化和飞行前检查后再进入滑行。
2. **地面服务**：在有效服务区域停机后，请求并管理加油、重新挂载、维修、外部电源以及其他地勤支援。
3. **弹射功能**：实现完整的紧急弹射流程，包括座舱盖分离、弹射座椅启动、降落伞展开和弹射后的飞行员状态。
4. **无线电语音系统**：加入与僚机、预警机/GCI、空中交通管制和地勤之间的交互式语音通信，包括情境化呼叫、指令确认和战术报告。
