# F-15C 无线电通信

无线电让 F-15C 与僚机、预警机/GCI、塔台和地勤保持协同。标准无线电信息通常包含呼号、指令或报告，以及必要的方位、距离、高度或状态说明。

## 信息结构

1. **呼号**：说明接收者和发话者。
2. **指令或报告**：例如攻击、返航、导弹发射或遭遇威胁。
3. **细节**：方位、距离、高度、目标类型、时钟方向或结果。

战斗中无线电时间有限，通话应尽量短而明确。

## 僚机指令

| 指令组 | 用途 |
| --- | --- |
| 攻击我的目标 | 命令僚机攻击本机指定目标 |
| 攻击敌机 | 命令僚机搜索并攻击空中威胁 |
| 掩护我 | 要求僚机处理正在威胁本机的目标 |
| 归队 | 要求僚机回到编队 |
| 沿航线飞行 / 返航 | 命令僚机继续任务航线或返回基地 |
| 雷达开/关 | 控制僚机雷达发射 |
| ECM 开/关 | 控制僚机电子干扰 |
| 拉烟开/关 | 视觉识别或表演用途 |
| 编队指令 | 调整编队形态和间距 |

僚机通常会用 `Copy`、`Roger`、`Affirm` 确认。如果不能执行，会回复 `Negative` 或 `Unable`。

## 预警机和 GCI

| 请求 | 返回信息 |
| --- | --- |
| Bogey dope | 最近敌方或未知空中目标的方位、距离、高度和态势 |
| Picture | 区域内目标群概况 |
| Vector to home plate | 到友方机场的方位和距离 |
| Vector to tanker | 到友方加油机的方位和距离 |

预警机信息依赖传感器覆盖和战场态势，应继续用本机雷达、TEWS 和目视确认。

## 空中交通管制

ATC 用于滑行、起飞、进近和着陆。常见请求包括滑行许可、起飞许可、进近请求和着陆许可。进近阶段塔台可能提供跑道、航向、间隔和下滑道修正。

## 地勤

在有效机场或服务区域停稳后，可向地勤请求加油、挂载、修理或调整载荷。具体可用项目取决于任务条件。

## 其他单位无线电信息

| 来源 | 常见含义 |
| --- | --- |
| 僚机 | 起飞滑跑、收轮、归队、攻击、防御、返航 |
| 僚机武器 | `Fox One`、`Fox Two`、`Fox Three`、`Guns`、`Winchester` |
| 僚机威胁 | Spike、Mud Spike、Missile Launch、SAM Launch |
| 预警机/GCI | 空情概况、合并警告、清空情、引导 |
| 塔台 | 滑行、起飞、着陆、等待、下滑道修正 |

## 语音告警系统

F-15C 的语音告警系统会提示关键故障和飞行状态。

| 触发条件 | 语音信息 |
| --- | --- |
| 右发失火 | `Engine fire right` |
| 左发失火 | `Engine fire left` |
| 飞控受损 | `Flight controls` |
| 高速时起落架放下 | `Gear down` |
| ILS 进近时起落架未放下 | `Gear up` |
| 达到返航油量 | `Bingo fuel` |
| 低油量 | `Fuel 1500`、`Fuel 800`、`Fuel 500` |
| 自动控制系统故障 | `ACS failure` |
| 导航系统故障 | `NCS failure` |
| ECM 故障 | `ECM failure` |
| 液压故障 | `Hydraulics failure` |
| 雷达故障 | `Radar failure` |
| 最大过载 | `Maximum G` |
| 最大迎角 | `Maximum angle of attack` |
| 临界速度 | `Critical speed` |
| 导弹告警 | `Missile` 加时钟方向和高低提示 |

听到语音告警后，先飞好飞机，再处理构型、故障或威胁。
