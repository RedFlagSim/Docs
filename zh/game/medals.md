# 奖牌

奖牌是永久成就。和有有效期的认证不同，奖牌一旦获得就不会过期。

## 奖牌如何获得

当你的账号进度达到某个里程碑时，系统会授予奖牌。游戏可能在飞行后、记录更新后、登录时或打开日志本时检查奖牌。

当前奖牌类别包括：

- 飞行时间里程碑；
- 生涯 XP 里程碑；
- 军衔进度；
- 空战结果；
- 导弹和机炮命中；
- 投弹次数；
- 机场降落表现和次数；
- 硬杆空中加油表现和次数。

## 例子

你可能因为这些行为获得奖牌：

- 完成第一次有效飞行；
- 达到 10、50、100 或 500 飞行小时；
- 达到重要生涯 XP 阶段；
- 晋升到更高军衔；
- 获得第一次空战胜利；
- 完成高分降落；
- 完成硬杆空中加油里程碑。

## 预留奖牌

部分奖牌族已经准备好，但对应玩法或评分还未完全开放，例如火箭攻击、舰船打击、航母降落和特殊精确打击评分。

这些奖牌可能会保持锁定，直到对应活动和记录路径开放。

## 获得提示

奖牌解锁时，游戏可能显示轻量弹窗。如果你错过了弹窗，日志本可以在之后回放待显示的奖牌通知。
