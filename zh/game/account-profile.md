# 账号与资料

Red Flag Sim 的账号和 Profile 是保存长期进度的基础。你的日志本、排行榜显示、认证资质、奖牌和生涯 XP 都会关联到当前玩家账号。

## 账号类型

你可以使用匿名账号快速进入游戏，适合先体验。但匿名账号更依赖当前设备和当前保存状态。

如果你打算长期游玩，建议绑定或登录 Unity ID。绑定账号更适合重装、换设备或未来恢复进度。

## Profile 会显示什么

你的 Profile 可以包含：

- 飞行员显示名称；
- 呼号；
- 中队或编队信息；
- 国家；
- 军衔和子等级；
- 生涯 XP；
- 总飞行时间；
- 用于进度系统的登录和活动记录。

排行榜和公开展示只会使用较轻量的公开资料，例如显示名称、呼号、头像、军衔、子等级和 XP。

## 如何保护进度

进度属于当前登录的玩家账号。切换账号后，游戏会切换到另一个账号自己的 Profile、飞行记录、认证和奖牌。

如果你一直使用匿名账号游玩，建议在重装或换设备前先绑定账号。这样更容易保留飞行员身份和长期进度。

## Profile 什么时候更新

以下情况都可能刷新 Profile：

- 登录游戏；
- 打开日志本；
- 完成飞行或技能事件；
- 获得生涯 XP；
- 获得或续期认证；
- 解锁奖牌。
