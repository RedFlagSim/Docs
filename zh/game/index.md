# 游戏系统

Red Flag Sim 会把你的飞行员进度保存到玩家账号下。Profile、生涯 XP、认证资质和奖牌都不是只存在于单次游戏或本地弹窗里，而是作为你的长期飞行记录维护。

## 会保存哪些内容

- **Profile**：飞行员名称、呼号、国家、军衔、子等级、XP 和总飞行时间。
- **生涯 XP**：来自飞行、训练、战斗、降落、空中加油、每日登录、认证和奖牌的长期经验。
- **认证资质**：对某项技能的认证，例如机场降落或硬杆空中加油；有些永久有效，有些需要定期续期。
- **奖牌**：永久成就，例如飞行小时、军衔进度、空战结果、降落和空中加油里程碑。
- **臂章**：保存在账号收藏中的游戏内收藏品。

## 系统如何维护你的成就

游戏不会只依赖本地弹窗来判断奖励是否获得。你的成绩、飞行记录、认证和奖牌会和账号进度进行核对，并保存到玩家历史中。

这意味着：

- 奖励和当前登录账号绑定；
- 重新打开游戏或日志本时，可以刷新进度；
- 如果网络或同步有延迟，奖励弹窗可能晚一点出现，但记录同步后仍可以补发；
- 部分未来认证或奖牌可能先显示为锁定，等对应训练或评分活动上线后再开放。
