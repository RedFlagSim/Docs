# 生涯 XP

生涯 XP 是飞行员账号的长期经验。它会推动军衔和子等级成长，也会反映你在不同模组和训练项目中的积累。

## 如何获得 XP

生涯 XP 可以来自以下来源：

- **每日登录**：连续登录奖励从 10 XP 开始，最高到 20 XP。
- **飞行时间**：当前规则为每 5 分钟有效飞行时间获得 5 XP。
- **武器活动**：导弹发射、机炮射击、武器命中和击杀可以提供 XP，但需要来自有效飞行记录。
- **降落表现**：机场降落分数越高，获得的 XP 档位越高。
- **空中加油**：完成加油、提高加油分数、接收燃油量都可以贡献 XP。
- **认证资质**：首次获得认证当前为 50 XP；续期认证为 15 XP。
- **奖牌**：部分奖牌会根据奖牌等级提供额外 XP。

游戏会限制重复刷低价值动作，让 XP 更接近真实飞行、训练和战斗进步，而不是单纯刷数值。

## 降落和加油分数档

技能分数越高，奖励越高：

| 活动 | 结果 | XP |
| --- | ---: | ---: |
| 机场降落 | 安全降落但低于 70000 | 5 |
| 机场降落 | 70000+ | 15 |
| 机场降落 | 85000+ | 60 |
| 机场降落 | 95000+ | 150 |
| 硬杆空中加油 | 完成加油 | 20 |
| 硬杆空中加油 | 70000+ | 20 |
| 硬杆空中加油 | 85000+ | 80 |
| 硬杆空中加油 | 95000+ | 200 |

如果你的最佳分从低档提升到高档，系统会按更高档位补充奖励。

## 军衔进度

生涯 XP 会推动军衔和子等级。每个军衔有 10 个子等级。

当前军衔顺序：

1. Cadet
2. SecondLt
3. FirstLt
4. Captain
5. Major
6. LtColonel
7. Colonel
8. BrigadierGeneral
9. MajorGeneral

XP 平衡可能随版本调整。你的 Profile 会显示按当前保存的生涯 XP 计算出的军衔和子等级。

## XP 什么时候出现

XP 可能在完成活动后立即出现，也可能在飞行记录同步、打开日志本或下次登录后出现。如果弹窗延迟，只要记录同步成功，进度仍可以补上。
