# 网站结构调整说明

Red Flag Sim 正在从单纯文档站升级为完整官方网站。

Docs 部分仍然用于承载手册、平台指南、飞机模组和游戏系统参考。新的站点结构会增加更清晰的产品入口、分组资源导航，以及用于发布开发更新的 Dev Blog。

## 为什么调整

项目现在需要的不只是参考文档。随着模拟器继续扩展，网站也需要解释产品定位、展示当前开发方向，并提供稳定的版本说明和工程开发记录入口。

## 主要变化

- Docs 成为官方网站中的一个模块。
- Dev Blog 成为开发动态和进展说明的入口。
- 导航围绕 Docs、Dev Blog、About 和 Support 组织。
- 视觉系统遵循 VitePress 的布局规范，并使用符合 RedFlagSim 品牌含义的红色高亮。
