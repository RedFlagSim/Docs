# 常见问题

本页说明当前项目中已经实现的行为。具体功能是否可用，应以设备上安装的版本和当前登录账号显示的访问权限为准。

## 项目与访问权限

### Red Flag Sim 目前处于什么阶段？有哪些飞机可用？

Red Flag Sim 正在持续开发中。F-15C 是当前最主要、文档最完整的核心模组，包括 F-5E 在内的其他飞机处于不同实现阶段。飞机出现在客户端或文档中，不代表它已在所有版本、游戏模式或账号中开放；请以已安装版本内的模组浏览器为准。另请参阅[关于 Red Flag Sim](/zh/about)和[飞机模组](/zh/Docs/aircraft/index)。

### 支持哪些平台和操控方式？

Red Flag Sim 面向移动平台和 VR 设计。当前移动端指南适用于 iOS 和 Android，使用设备姿态与触摸操作。飞行时应竖直握持设备，以日常飞行姿势完成校准；坐姿改变后应重新校准。平台可用性和功能覆盖范围以当前发布版本为准。详见[移动平台飞行员手册](/zh/Docs/basics/mobile-platform)。

### 为什么能看到模组、改型、功能或涂装，却无法进入任务？

“已列出”和“可访问”是两回事。任务启动时会分别检查飞机模组、当前启用的改型功能以及非默认涂装包是否属于当前账号。商店页面或目录条目本身不能证明已经拥有内容。请确认设备联网、登录的是正确账号，并且当前账号已拥有所需内容，或该内容已在当前游戏模式中开放。

## 账号、网络与购买

### 可以离线游玩吗？怎样保护进度？

不要把它视为完整离线游戏。客户端会保留部分本地记录，但登录、云同步、权限检查、购买和排行榜依赖在线服务。匿名账号也依赖当前设备保留的账号状态。重装游戏、更换设备或长期积累进度前，建议关联或登录 Unity Player Account。详见[账号与资料](/zh/Docs/game/account-profile)。

### 已购买内容没有显示时怎么办？

先确认当前使用的是购买时相同的已关联玩家账号和平台商店账号。恢复网络、刷新商店，并在界面提供该选项时使用“恢复购买”。如果仍然没有权限，请联系支持并提供玩家 ID、商品名称、平台、大致购买时间和平台交易 ID。不要发送银行卡号或账号密码。

## 进度、评分与奖励

### 哪些进度会被保存？为什么更新可能延迟？

账号进度可包括飞行员资料、生涯 XP、军衔、飞行时间、模组记录、技能最佳分、认证资质、奖牌、臂章、解锁内容和所有权。部分详细的单次飞行历史也会保存在本地。单次飞行结果、云端汇总、奖励和排行榜聚合是不同的步骤，因此临时网络问题可能导致弹窗或排名延迟。恢复网络并等待同步完成后，再重新打开飞行日志或排行榜。详见[游戏系统](/zh/Docs/game/index)。

### 为什么手动降落或硬杆空中加油没有获得评分？

机场手动降落评分要求有效进近并完成完整滑跑。常见无效原因包括：进入评分区域时速度超出支持范围、ILS 或禁止使用的自动辅助仍处于启用状态、进近或接地指标超限，以及在跑道末端前未充分减速。硬杆空中加油在成功完成后记录，评分会考虑连接时间、进入速度、漂移和中心位置精度。具体限制可能随飞机配置不同而变化。

### 认证资质、奖牌和臂章有什么区别？

- **认证资质**用于证明某项技能；部分资质会到期，需要续期。
- **奖牌**一旦授予就是永久成就。
- **臂章**是账号收藏品，不代表通过技能认证。

部分条目为尚未完整接入的玩法预留，因此可能保持锁定。详见[认证资质](/zh/Docs/game/qualifications)、[奖牌](/zh/Docs/game/medals)和[臂章](/zh/Docs/game/patches)。

## 飞行行为与文档

### 为什么任务航向与驾驶舱显示的磁航向不同？

空中出生所用的任务航向和内部飞行航向以真北为基准。驾驶舱或导航显示可能会根据当地磁偏角换算为磁航向，因此两者出现差值是正常现象，且差值会随地理位置变化。

### 不同版本之间，系统和文档会变化吗？

会。系统行为、访问规则、评分阈值和 UI 流程都可能调整。英文是源文档，其他八种语言并行维护，并进行页面完整性检查。如果翻译页面与已安装版本不一致，请以当前版本为准，并反馈文档差异。

### 如何报告问题或寻求账号帮助？

请发送邮件至 **dev@redflagsim.com**，或按[用户反馈](/zh/feedback)页面的说明提交。建议附上游戏版本、设备型号、操作系统版本、相关玩家 ID、复现步骤、预期结果与实际结果，以及可用的截图或视频。隐私或数据删除请求请参阅[隐私声明](/zh/privacy-policy)。
