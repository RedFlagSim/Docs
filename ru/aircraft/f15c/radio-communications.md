# Радиосвязь F-15C

Радио связывает F-15C со звеном, AWACS/GCI, диспетчерами и наземной командой. Сообщение указывает адресата, требуемое действие и необходимую тактическую информацию.

## Структура сообщения

1. Позывной: получатель и отправитель, например `Chevy 22, Chevy 21`.
2. Команда или доклад: действие либо состояние, например `engage bandits` или `missile launch`.
3. Подробности: направление, дальность, высота, тип цели, направление по часам или результат.

Говорите коротко и точно. В бою время радиоэфира тоже является ресурсом.

## Команды звену и ведомым

| Группа команд | Назначение |
| --- | --- |
| Engage my target | Атаковать назначенную игроком цель |
| Engage bandits | Искать и атаковать воздушного противника |
| Cover me | Поражать наиболее непосредственную угрозу игроку |
| Rejoin | Вернуться в строй |
| Go to route / RTB | Следовать маршруту или на базу |
| Radar on/off | Управлять излучением РЛС ведомого |
| ECM on/off | Управлять его помехами |
| Smoke on/off | Визуальное опознавание или пилотажный дым |
| Formation commands | Менять интервалы и геометрию строя |

Обычно ведомые подтверждают `Copy`, `Roger` или `Affirm`. Если выполнить невозможно — `Negative` или `Unable`.

## Запросы AWACS и GCI

Воздушные и наземные контролёры могут дать обстановку, когда ваша РЛС молчит, подавлена или занята другим направлением.

| Запрос | Получаемая информация |
| --- | --- |
| Bogey dope | Направление, дальность, высота и ракурс ближайшего противника или неизвестного самолёта |
| Picture | Сводка обнаруженных групп в районе |
| Vector to home plate | Направление и дальность ближайшего подходящего дружественного аэродрома |
| Vector to tanker | Направление и дальность ближайшего дружественного заправщика |

Достоверность зависит от покрытия датчиков и осведомлённости коалиции. Продолжайте проверки РЛС, TEWS и визуальным наблюдением.

## Управление воздушным движением

ATC применяется при движении по земле, взлёте, заходе и посадке. Обычные запросы:

- Разрешение на руление
- Разрешение на взлёт
- Запрос возвращения или захода
- Разрешение на посадку
- Уход на второй круг или указания интервала

На заходе вышка может сообщать полосу, курс, интервалы и поправки к глиссаде.

## Наземная команда

Команды доступны на стоянке подходящей базы или зоны обслуживания. В зависимости от задания возможны заправка, перевооружение, ремонт и изменение подвесок.

## Сообщения других подразделений

| Источник | Пример значения |
| --- | --- |
| Ведомый | Разбег, уборка шасси, сбор, атака, оборона, возвращение |
| Применение оружия ведомым | `Fox One`, `Fox Two`, `Fox Three`, `Guns`, `Winchester` |
| Доклады ведомого об угрозах | Захват РЛС, захват наземной РЛС, пуск ракеты или ЗРК |
| AWACS/GCI | Обстановка противника, предупреждение сближения, угроз нет, векторы |
| ATC | Руление, взлёт, посадка, ожидание по кругу, поправка глиссады |

## Система речевых предупреждений

Речевой информатор F-15C, обычно называемый Betty, сообщает срочные состояния и отказы.

| Условие | Речевое сообщение |
| --- | --- |
| Пожар правого двигателя | `Engine fire right` |
| Пожар левого двигателя | `Engine fire left` |
| Повреждение управления | `Flight controls` |
| Шасси выпущено выше безопасной скорости | `Gear down` |
| Шасси убрано на заходе ILS | `Gear up` |
| Достигнут заданный остаток bingo | `Bingo fuel` |
| Мало топлива | `Fuel 1500`, `Fuel 800`, `Fuel 500` |
| Отказ автопилота/управления | `ACS failure` |
| Отказ навигационного компьютера | `NCS failure` |
| Отказ ECM | `ECM failure` |
| Отказ гидравлики | `Hydraulics failure` |
| Отказ РЛС | `Radar failure` |
| Превышена максимальная перегрузка | `Maximum G` |
| Превышен максимальный угол атаки | `Maximum angle of attack` |
| Критическая скорость | `Critical speed` |
| Ракетная угроза | `Missile` с последующим направлением по часам и указанием выше/ниже. |

Рассматривайте предупреждения как приоритет. Осознайте угрозу или отказ, сначала управляйте самолётом, затем меняйте конфигурацию или обороняйтесь.
