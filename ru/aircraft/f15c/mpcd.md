# MPCD

MPCD (Multi-Purpose Color Display) — многопрофильный цветной дисплей F-15C для оружия: полезная нагрузка, боекомплект и контекст сопровождения цели.

Эта страница описывает взаимосвязь MPCD с HUD, VSD и Touch UI. Полные пояснения по каждому блоку будут добавляться поэтапно.

- В некоторых режимах поворот `castle` вправо позволяет перейти в режим управления загрузкой/боекомплектом на MPCD.
- Значения MPCD следует проверять вместе с VSD/HUD; по ним нельзя единолично считать, что ракета уже готова к пуску.
