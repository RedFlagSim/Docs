# Обновление структуры сайта

RedFlagSim переходит от сайта документации к полноценному официальному сайту.

Docs остаётся местом для руководств, модулей самолётов и игровых систем. Новая структура добавляет Dev Blog, Support и отдельную страницу About.

Документация остаётся местом для руководств, платформенных инструкций, модулей самолётов и игровых систем. Новая структура добавляет понятную точку входа в продукт, сгруппированную навигацию по ресурсам и отдельный блог разработки.

## Причина изменений

Проекту нужны не только справочные материалы. По мере роста симулятора сайт должен объяснять продукт, показывать направление разработки и служить постоянным местом для заметок о версиях и технических обновлений.

## Основные изменения

- Docs становится одним из модулей официального сайта.
- Dev Blog содержит новости и ход разработки.
- Support объединяет отзывы, политики и официальные каналы.
- Оформление следует структуре VitePress с красным акцентом RedFlagSim.

Навигация организована вокруг документации, блога, информации о проекте и поддержки.
