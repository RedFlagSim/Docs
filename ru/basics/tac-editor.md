### 1. Flight — звено

**Flight** — звено из **не более 4 самолётов**. Каждая карточка вверху обозначает одно звено, а значки самолётов показывают его состав. Выберите карточку, чтобы просмотреть звено и настроить самолёты.

[Перейти к Flight](#part-2-flight)

[К указателю](#ui-terms-top)

<a id="item-2"></a>

### 2. Bullseye — опорная точка

**Bullseye** — общая географическая опорная точка для передачи направлений и расстояний. Её положение на карте отмечено жёлтыми концентрическими окружностями.

Дистанционные кольца на карте имеют общий центр в точке Bullseye. Радиусы соседних колец отличаются на **20 морских миль (20 NM)**.

[К указателю](#ui-terms-top)

<a id="item-3"></a>

### 3. Package — группа звеньев

**Package** объединяет звенья одной стороны. Синие и красные полосы вверху содержат звенья соответствующих групп. Выберите группу для просмотра и управления её звеньями.

[Перейти к Package](#part-2-package)

[К указателю](#ui-terms-top)

### 5. Inspector — панель свойств

Выбор **Scenery** сейчас недоступен. Выбирать регион карты здесь можно будет в будущей версии, когда появится поддержка нескольких регионов.

### 6. Масштаб

Масштабная линейка показывает расстояние, соответствующее её длине при текущем увеличении. **NM** означает морские мили; в примере указано **16.66 NM**. Используйте линейку для оценки расстояний на карте.

[К указателю](#ui-terms-top)

<a id="item-7"></a>

### 7. Панель карты

Внизу слева расположены четыре кнопки, слева направо:

- **Перемещение** (четыре стрелки): удерживайте для перемещения выбранного элемента карты.
- **Приблизить** (лупа с +): увеличить карту.
- **Отдалить** (лупа с −): показать большую область.
- **Home** (дом): закрыть редактор и вернуться на главный экран.

::: tip Перемещение элемента карты
1. Выберите нужный юнит или элемент.
2. **Левой рукой удерживайте кнопку перемещения**.
3. Продолжая удерживать её, **правой рукой перетаскивайте по карте**, чтобы изменить положение выбранного элемента.
:::

## Часть 2: Package и Flight

Сначала объедините звенья в Package, затем откройте Flight для настройки состава и задачи. Панели ниже следуют этой иерархии.

Иерархия самолётов: **Mission → Package → Flight → Slot (один самолёт)**. Каждое звено Flight входит в одну группу Package и содержит до **4 самолётов**.

<a id="part-2-package"></a>

### Package (группа)

Выберите Package в верхней части карты, чтобы увидеть звенья и время группы. В примере группа называется blue1.

<TacInspectorPanel panel="package" alt="Package Inspector" open-label="Открыть изображение в полном размере.">

**Поля и управление**

- <strong>Название и список Flight</strong>: Сверху указано название группы; нажмите на него, чтобы переименовать группу. Ниже — Flight1, Flight2 и Flight3. Номера обозначают самолёты внутри каждого звена.
- <strong>＋</strong>: Добавить Flight. Выберите существующую карточку, чтобы открыть Flight Inspector.
- <strong>Take-off Time</strong>: Время взлёта группы; в примере 23:03.
- <strong>Time on Target (TOT)</strong>: Время прибытия группы к цели; в примере 23:33.

</TacInspectorPanel>

[Вернуться к обзору интерфейса](#item-3)

<a id="part-2-flight"></a>

### Flight (звено)

Выберите Flight внутри Package, чтобы увидеть состав и настройки. В примере Flight1 состоит из 4 самолётов.

<TacInspectorPanel panel="flight" alt="Flight Inspector" open-label="Открыть изображение в полном размере.">

**Поля и управление**

- <strong>Схема состава</strong>: Показывает самолёты и номера. Выбор самолёта открывает его Slot Inspector.
- <strong>Airbase</strong>: База звена; в примере NAS_Fallon.
- <strong>Mission Role</strong>: Задача звена; в примере CAP.
- <strong>Take-off Time / Time on Target</strong>: Время взлёта и прибытия к цели; в примере 23:03 и 23:12.
- <strong>Station Time</strong>: Продолжительность патрулирования между двумя маршрутными точками целевого типа при выполнении патрульной задачи; задаётся в минутах.
- <strong>Steer Points</strong>: Открыть редактирование маршрута. Подробности о маршруте и точках — в части 4.
- <strong>Rebuild</strong>: Пересчитать Time on Target (TOT, время прибытия к цели) для Flight.
- <strong>Delete</strong>: Находится под Rebuild. Удаляет всё определение Flight, а не один самолётный Slot.

</TacInspectorPanel>

<a id="flight-station-time-example"></a>

#### Пример патрулирования: заправщики и самолёты ДРЛО

Чтобы заправщик или самолёт ДРЛО патрулировал заданный район:

1. Разместите две маршрутные точки в месте будущего патрулирования и задайте обеим <strong>целевой тип</strong>.
2. В Flight Inspector задайте нужную продолжительность патрулирования в минутах в поле <strong>Station Time</strong>.
3. Самолёт будет патрулировать между этими двумя целевыми точками в течение времени, заданного Station Time.

## Часть 3: Настройка самолётов

<a id="part-3-slot"></a>

### Slot (отдельный самолёт)

Slot представляет один самолёт в Flight. Выберите самолёт на схеме состава звена, чтобы открыть его Inspector.

<TacInspectorPanel panel="slot" alt="Slot (отдельный самолёт) Inspector" open-label="Открыть изображение в полном размере.">

**Поля и управление**

- <strong>Тип и номер самолёта</strong>: Сверху показан F-15C под номером 1. Выпадающий список ниже выбирает тип самолёта.
- <strong>Loadout / Livery</strong>: Открыть настройки вооружения и окраски.
- <strong>Spawn Type</strong>: Выбрать Airborne (в воздухе) или Airbase (на базе). На снимке выбран Airbase.
- <strong>Spawn Point ID</strong>: Выбор точки появления; в примере Auto.
- <strong>Initial State</strong>: Открыть настройки начального состояния самолёта.
- <strong>Delete</strong>: Удалить текущий Slot, а не весь Flight или Package.

</TacInspectorPanel>

## Часть 4: План полёта

Откройте Steer Points в Flight Inspector для редактирования маршрутных точек текущего звена. На снимке выбрана точка с номером 3.

[Подробное описание: Flight Inspector](#part-2-flight)

<a id="part-4-steerpoints"></a>

### Steer Points (маршрутные точки)

<TacInspectorPanel panel="steerpoints" alt="Steer Points (маршрутные точки)" open-label="Открыть изображение в полном размере.">

**Поля и управление**

- <strong>Стрелки и номер</strong>: Стрелки переключают точки. В центре показан номер выбранной точки; в примере 3.
- <strong>Тип точки</strong>: Выберите тип в раскрывающемся списке. На снимке выбран Target (целевая точка).
- <strong>Elev (MSL)</strong>: Плановая высота в точке относительно среднего уровня моря (MSL), в футах (FT). В примере 15000 FT; это не высота над землёй.
- <strong>KCAS</strong>: Плановая калиброванная воздушная скорость в точке, в узлах. Показано 529 KCAS; это не путевая или истинная воздушная скорость.
- <strong>Time(Z) Over Steerpoint</strong>: Плановое время прохождения точки по Zulu (UTC). Слева часы, справа минуты: в примере 23:15 Z. Это не длительность полёта.
- <strong>New</strong>: Добавить маршрутную точку.
- <strong>Delete</strong>: Удалить выбранную точку, а не весь Flight.

</TacInspectorPanel>

Для патрулирования заправщика или самолёта ДРЛО разместите две точки типа Target в районе патруля и задайте его длительность между ними через Station Time звена. Чтобы пересчитать TOT звена, нажмите Rebuild в Flight Inspector.
