# Примеры расширений Markdown

Здесь показаны некоторые встроенные расширения Markdown в VitePress.

## Подсветка синтаксиса

VitePress использует [Shiki](https://github.com/shikijs/shiki) для подсветки синтаксиса и поддерживает выделение строк:

**Ввод**

````md
```js{4}
export default {
  data () {
    return {
      msg: 'Highlighted!'
    }
  }
}
```
````

**Вывод**

```js{4}
export default {
  data () {
    return {
      msg: 'Highlighted!'
    }
  }
}
```

## Пользовательские контейнеры

**Ввод**

```md
::: info Информация
Это информационный блок.
:::

::: tip Совет
Это совет.
:::

::: warning Предупреждение
Это предупреждение.
:::

::: danger Опасность
Это предупреждение об опасности.
:::

::: details Подробнее
Это блок подробностей.
:::
```

**Вывод**

::: info Информация
Это информационный блок.
:::

::: tip Совет
Это совет.
:::

::: warning Предупреждение
Это предупреждение.
:::

::: danger Опасность
Это предупреждение об опасности.
:::

::: details Подробнее
Это блок подробностей.
:::
