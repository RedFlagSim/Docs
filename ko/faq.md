# FAQ

## 현재 프로젝트 단계는 무엇인가요?

Red Flag Sim은 활발히 개발 중이며 시스템과 문서는 지속적으로 업데이트됩니다.

## 현재는 F-15C만 플레이 가능한가요?

F-15C는 현재 첫 번째 핵심 플레이 가능 모듈이며, 추가 모듈은 개발 중입니다.

## 버전이 바뀌면 시스템도 바뀌나요?

네. 시뮬레이션 충실도가 높아지면서 시스템 동작과 운용 절차가 계속 개선됩니다.

## 다국어는 어떻게 유지하나요?

영어를 소스 언어로 사용하고 각 언어 페이지를 병행 업데이트합니다. CI의 i18n 체크로 누락을 방지합니다.
