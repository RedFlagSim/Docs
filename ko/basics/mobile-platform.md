# 모바일 플랫폼 조종 매뉴얼

이 문서는 iOS/Android 모바일 기기에 적용됩니다.

## 핵심 규칙: 수직으로 잡기

정확한 자세 제어를 위한 기본 단계입니다.

![핵심 규칙: 수직으로 잡기](/assets/tilt-guide.png)

- ❌ 잘못된 자세: 휴대폰을 수평으로 눕혀 잡기. 이 자세에서는 롤과 요 축이 결합되어 롤 입력을 안정적으로 구분하기 어렵습니다.
- ✅ 기준 자세: 양손으로 기기를 잡고 화면을 지면에 수직으로 세워 자신을 향하게 합니다.

### 왜 수직으로 잡아야 하나요?

모션 조작은 롤 축을 명확하게 구분해야 합니다. 기기를 눕히면 자세 계산 과정에서 롤과 요 축이 결합되어 사용자가 롤과 요 중 어느 것을 입력했는지 안정적으로 구분할 수 없습니다. 따라서 수직 자세를 모션 조작의 기준으로 사용해야 합니다.

## 조작 입력

- 피치(승강타): 휴대폰 위쪽을 뒤로, 몸 쪽으로 기울이면 기수를 들어 상승합니다. 앞으로, 몸에서 멀어지는 쪽으로 기울이면 기수를 내려 강하합니다.
- 롤(보조익): 운전대를 돌리듯 휴대폰을 좌우로 회전합니다.

## 터치 가상 조이스틱

모바일 버전은 모션 조작 대신 화면의 가상 조이스틱도 지원합니다. 기기를 움직이지 않고 조종하려면 비행 전에 가상 조이스틱 모드를 선택하세요.

![터치 가상 조이스틱](/assets/mobile-virtual-stick.jpeg)

- 피치: 스틱을 아래로 끌면 기수가 올라가고 위로 끌면 기수가 내려갑니다.
- 롤: 좌우로 끌면 해당 방향으로 롤합니다.
- 중립 복귀: 손을 떼면 자동으로 중앙으로 돌아옵니다.

수직 자세와 보정 조건은 모션 조작에만 적용됩니다. 터치 가상 조이스틱은 보기 편한 자세로 기기를 잡아도 됩니다.

## 비행 전 설정과 정밀 조작 요령

1. 기준 설정(보정): 조종석에 들어간 후 또는 이륙 전에 편하게 앉아 기기를 수직으로 안정되게 잡고 주 메뉴에서 Calibrate Gyro를 누릅니다. 현재 각도가 중립 영점으로 기록됩니다.

    ![비행 전 설정과 정밀 조작 요령](/assets/mobile-gyro-calibration.jpeg)

2. 안정적인 조작: 밀집 편대, 공중 급유, 근접 공중전에서는 팔꿈치를 무릎이나 팔걸이에 받칩니다. 몸의 떨림을 줄여 1도 미만의 정밀한 조작을 돕습니다.

## 터치 UI 편집 모드

화면의 빈 곳을 빠르게 네 번 연속 누르면 편집 모드가 열립니다. 주 메뉴의 `UI Editor`에서도 열 수 있습니다.

![터치 UI 편집 모드](/assets/mobile-ui-editor.jpeg)

편집 모드에서 가능한 작업:

- 컨트롤 재배치: 컨트롤을 선택하고 이동하여 화면 배치를 바꿉니다.
- 투명 모드: `CLEAR MODE`로 투명 표시로 전환합니다.
- 전체 불투명도: 터치 UI가 비행 시야를 가리는 정도를 줄입니다.
- 플로팅 MFD 설정: 다기능 디스플레이의 크기와 표시 여부를 조절합니다. 자세한 설명은 [F-15C 터치 UI 문서](/ko/Docs/aircraft/f15c/touch-ui.html#item-3)를 참조하세요.
