# F-15C 조종석 계기

F-15C 조종석은 HUD, 수직 상황 디스플레이(VSD), 전술 전자전 시스템(TEWS)이라는 세 전투 표시를 중심으로 구성됩니다. 엔진, 항법, 연료, 무장과 대응책 계기는 그 아래와 주변에 배치되어 전투에 집중하면서 기체 상태를 교차 확인할 수 있습니다.

## 전투 디스플레이

<a id="instrument-3"></a>

### 수직 상황 디스플레이(VSD)

VSD는 F-15C의 레이더 화면입니다. 탐색 공간, 표적 반사파, 락온 상태와 가시거리 밖 교전에 필요한 표적 정보를 보여 줍니다. 절차와 기호는 레이더 장에서 설명합니다.

![수직 상황 디스플레이(VSD)](/assets/F-15C/Manual/fig-21-vsd.png)

<a id="instrument-9"></a>

### 전술 전자전 시스템(TEWS)

TEWS는 레이더 경보 화면입니다. 자기 기체 주위에 레이더 방사원을 표시하고 가장 위험한 위협에 우선순위를 부여하며 미사일 발사 표시와 ECM 상태를 보여 줍니다.

![전술 전자전 시스템(TEWS)](/assets/F-15C/Manual/fig-22-tews-display.png)

<a id="instrument-1"></a>

### 다목적 컬러 디스플레이 / 무장 통제 패널

#### SIT 상황 표시

SIT는 전장을 위에서 내려다보는 형태로 표시합니다. 데이터링크로 자기 기체, 아군과 적기를 보여 주며 여러 지오펜스, 나침반, Zulu 시각과 불스아이 좌표도 표시할 수 있습니다. 커서는 VSD에 연동하거나 연동을 해제해 독립 조작할 수 있습니다.

![SIT 상황 표시](/assets/F-15C/Manual/fig-23-mpcd-sit-display.png)

#### AA 무장 상태 패널

![AA 무장 상태 패널](/assets/F-15C/Manual/fig-23-mpcd-weapons-panel.png)

AA 페이지는 외부 탱크, 무장 종류, 기관포 탄약, 채프와 플레어 잔량을 표시합니다. `FUEL`은 장착된 탱크, `PYLON`은 빈 장착 지점입니다. 무장 선택과 전체 표시는 [MPCD 장](/ko/Docs/aircraft/f15c/mpcd.html)을 참조하십시오.

## 비행 계기

<a id="instrument-12"></a>

### 착륙장치 레버

착륙장치 전개와 수납을 명령합니다.

<a id="instrument-13"></a>

### 착륙장치 위치 표시기

착륙장치가 내려가 잠겼는지 확인합니다.

<a id="instrument-2"></a>

### 지시 대기 속도와 마하수

MPCD 오른쪽에 있으며 고정 눈금은 50~1000노트의 지시 대기 속도를 나타냅니다. 마하 바늘은 약 200노트 이상에서 유용합니다.

![지시 대기 속도와 마하수](/assets/F-15C/Cockpit/indicated-airspeed-mach.png)

<a id="instrument-14"></a>

### 받음각 지시계

기하학적 각도가 아닌 F-15 받음각 단위로 표시합니다. 접근, 저속 기동, 높은 받음각에서의 회복에 사용합니다. 정상 착륙 목표는 약 20~22단위입니다.

![받음각 지시계](/assets/F-15C/Manual/fig-25-aoa-indicator.png)

<a id="instrument-15"></a>

### 가속도계

현재 G 하중과 출격 중 최대 양·음의 G를 기록합니다. 격렬한 기동 뒤 기체 구조가 받은 하중을 교차 확인하는 데 사용합니다.

![가속도계](/assets/F-15C/Cockpit/accelerometer.png)

### 중앙 ADI, HSI와 인접 조작부

![중앙 ADI, HSI와 인접 조작부](/assets/F-15C/Cockpit/adi-hsi-emergency-jettison-steering-mode.png)

<a id="instrument-4"></a>

#### 자세 지시계(ADI)

ADI는 주요 피치·뱅크 기준입니다. 회전 구체는 피치 5도, 뱅크 10도 간격이며 30도마다 큰 표시가 있습니다. 수직·수평 지시봉은 선택한 항법원의 유도 명령을 표시하고 아래의 선회·미끄럼 표시는 조화된 선회를 돕습니다. 해당 기능을 사용할 수 있으면 옆 선택기로 INS 또는 AHRS 자세 기준을 선택합니다.

<a id="instrument-16"></a>

#### 수평 상황 지시계(HSI)

HSI는 항법 상황을 평면으로 보여 줍니다. 회전 나침반 카드의 상단 기준 아래에 기체 기수가 위치하며 코스 화살표와 편차 막대는 선택 코스와 좌우 오차를 표시합니다. 왼쪽 위 계수기는 해리 거리, 오른쪽 위는 선택 코스입니다. COURSE SET와 HEADING SET 노브로 각 기준을 설정합니다. ILS 접근 시 코스 편차를 ADI와 HUD 유도와 함께 사용합니다.

<a id="instrument-22"></a>

#### 비상 투하 버튼

ADI 바로 왼쪽의 보호된 노랑·검정 <strong>PUSH TO JETT</strong> 버튼은 투하 가능한 외부 장착물을 비상 투하합니다. 즉각적인 하중 감소가 필요할 때만 사용하며 실제 투하 대상은 기체 구성과 임무 규칙에 따릅니다.

<a id="instrument-23"></a>

#### 유도 모드 선택기

비상 투하 버튼 아래의 선택기는 HSI, ADI, HUD 유도 정보의 항법원을 선택합니다.

- <strong>NAV:</strong> 항로와 항법점 유도.
- <strong>TCN:</strong> TACAN 방위·거리·선택 코스 유도.
- <strong>ILS NAV:</strong> ILS 로컬라이저·글라이드슬로프와 NAV 유도 결합.
- <strong>ILS TCN:</strong> ILS와 TACAN 유도 결합.

<a id="instrument-17"></a>

### 기내 시계

조종석 시간 기준이며 임무 시간 관리와 항법 교차 확인에 쓰는 Zulu 시각을 표시합니다.

![기내 시계](/assets/F-15C/Cockpit/aircraft-clock.png)

### 고도계와 수직 속도계

![고도계와 수직 속도계](/assets/F-15C/Cockpit/altimeter-vvi.png)

<a id="instrument-6"></a>

#### 기압 고도계

계수기와 바늘로 피트 단위 고도를 표시합니다. 드럼은 주 고도값, 바늘은 더 세밀한 값을 보여 줍니다. 기압 설정 노브로 필요한 현지 값을 입력하세요. 잘못 설정하면 표시 고도도 틀립니다.

<a id="instrument-5"></a>

#### 수직 속도계(VVI)

VVI는 상승·하강률을 분당 천 피트로 표시합니다. 시계 방향은 상승, 반시계 방향은 하강입니다.

## 엔진과 연료 계기

### 엔진 회전수와 온도

![엔진 회전수와 온도](/assets/F-15C/Cockpit/tachometer-ftit.png)

<a id="instrument-8"></a>

#### 회전계

두 회전계는 좌우 엔진 RPM을 0~110%로 표시합니다. 시동, 지상 활주, 이륙 점검과 스로틀 확인 시 바늘과 계수기를 함께 봅니다.

<a id="instrument-7"></a>

#### 팬 터빈 입구 온도(FTIT)

두 FTIT 계기는 0~1400 °C를 표시합니다. 바늘은 연속적인 값을, 계수기는 확인하기 쉬운 숫자를 제공합니다. 비정상적으로 높으면 터빈 과열이므로 신속히 주의해야 합니다.

### 연료 유량과 배기 노즐 위치

![연료 유량과 배기 노즐 위치](/assets/F-15C/Cockpit/fuel-flow-nozzle-position.png)

<a id="instrument-18"></a>

#### 엔진 연료 유량

후연기 유량을 포함한 엔진 총 공급 연료를 시간당 파운드로 표시합니다. 연료량과 함께 소비량을 감시하고 엔진이나 연료 계통의 이상을 확인합니다.

<a id="instrument-19"></a>

#### 엔진 노즐 위치

완전 개방에 대한 배기 노즐 개방 비율을 표시합니다. 엔진 출력과 후연기 작동에 따라 변합니다.

### 유압과 엔진 오일 압력

![유압과 엔진 오일 압력](/assets/F-15C/Cockpit/hydraulic-oil-pressure.png)

<a id="instrument-24"></a>

#### 유압 지시계

세 계기는 <strong>PC1</strong>, <strong>PC2</strong>, <strong>UTIL</strong> 압력을 0~4000 psi로 표시합니다. PC1과 PC2는 비행 제어에, UTIL은 착륙장치·브레이크·전륜 조향 등에 공급합니다. 정상 압력은 약 3000 psi이며 큰 감소나 0 표시는 영향을 받은 계통을 식별하는 데 도움이 됩니다.

<a id="instrument-25"></a>

#### 엔진 오일 압력계

아래 두 계기는 좌우 엔진 오일 압력을 0~100 psi로 표시합니다. 두 엔진을 비교하고 낮은 값은 해당 주의 표시와 교차 확인하세요.

<a id="instrument-10"></a>

### 연료량

바늘은 내부 총 연료를 천 파운드 단위로 표시합니다. 위 계수기는 총 연료, 아래 LEFT·RIGHT 계수기와 선택기는 개별 탱크 잔량과 표시기 점검에 사용합니다.

![연료량](/assets/F-15C/Cockpit/fuel-quantity.png)

## 압력과 대응 수단

<a id="instrument-20"></a>

### 조종석 압력계

등가 조종석 고도를 표시합니다. 손상이나 여압 고장으로 표시 고도가 10000피트에 가까워지면 신속히 하강하세요.

![조종석 압력계](/assets/F-15C/Cockpit/cabin-pressure.png)

<a id="instrument-11"></a>

### 채프와 플레어 표시등

살포 중 약 3초간 깜박입니다. 잔량이 매우 적으면 최소 잔량 경고등이 켜집니다.

![채프와 플레어 표시등](/assets/F-15C/Cockpit/chaff-flare-indicators.png)

<a id="instrument-21"></a>

### 경고등 패널

항공기 계통 경고를 표시합니다.
