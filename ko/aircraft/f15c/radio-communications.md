# F-15C 무선 통신

무선은 F-15C를 편대, AWACS/GCI, 관제와 지상 요원에 연결합니다. 기본 형식은 호출 대상, 요청 동작, 실행에 필요한 전술 정보입니다.

## 메시지 구조

1. 호출부호: 수신자와 발신자. 예: `Chevy 22, Chevy 21`.
2. 명령 또는 보고: 행동이나 상태. 예: `engage bandits`, `missile launch`.
3. 세부 사항: 방위, 거리, 고도, 표적 종류, 시계 방향 또는 결과.

짧고 정확하게 말하세요. 전투에서는 무선 시간도 자원입니다.

## 편대와 윙맨 명령

| 명령 그룹 | 용도 |
| --- | --- |
| Engage my target | 플레이어가 지정한 표적 공격 |
| Engage bandits | 공중 적기 탐색 및 공격 |
| Cover me | 플레이어에게 가장 직접적인 위협에 대응 |
| Rejoin | 편대로 복귀 |
| Go to route / RTB | 계획 항로 진행 또는 기지 귀환 |
| Radar on/off | 윙맨 레이더 방사 제어 |
| ECM on/off | 윙맨 재밍 제어 |
| Smoke on/off | 육안 식별 또는 곡예 연막 |
| Formation commands | 간격과 대형 조절 |

윙맨은 보통 `Copy`, `Roger`, `Affirm`으로 짧게 응답합니다. 수행할 수 없으면 `Negative`나 `Unable`로 답합니다.

## AWACS와 GCI 요청

자기 레이더가 침묵 중이거나 방해받거나 다른 방향에 집중할 때 조기경보기나 지상 관제가 전술 상황을 제공할 수 있습니다.

| 요청 | 제공 정보 |
| --- | --- |
| Bogey dope | 가장 가까운 적기 또는 미확인기의 방위·거리·고도·상대 기수각 |
| Picture | 구역 내 탐지된 기체 그룹 요약 |
| Vector to home plate | 가장 가까운 적합한 아군 비행장의 방위와 거리 |
| Vector to tanker | 가장 가까운 아군 급유기의 방위와 거리 |

보고의 품질은 센서 범위와 진영이 파악한 정보에 제한됩니다. 레이더, TEWS와 육안 확인을 계속하세요.

## 항공 교통 관제

ATC는 지상 이동, 이륙, 접근, 착륙에 사용합니다. 일반적인 요청:

- 지상 활주 허가
- 이륙 허가
- 귀환 또는 접근 요청
- 착륙 허가
- 복행 또는 간격 지시

접근 중에는 활주로, 코스, 항공기 간격과 강하 경로 수정이 전달될 수 있습니다.

## 지상 요원

유효한 공항이나 서비스 구역에 주기 중 사용할 수 있습니다. 임무 조건에 따라 급유, 재무장, 수리와 무장 구성을 조정합니다.

## 다른 유닛의 무선 메시지

| 출처 | 의미 예시 |
| --- | --- |
| 윙맨 | 이륙 활주, 바퀴 수납, 재합류, 교전, 방어, 귀환 |
| 윙맨 무장 보고 | `Fox One`, `Fox Two`, `Fox Three`, `Guns`, `Winchester` |
| 윙맨 위협 보고 | 레이더 락온, 지상 레이더 락온, 미사일 발사, SAM 발사 |
| AWACS/GCI | 적 상황, 근접 교차 경고, 위협 없음, 유도 |
| ATC | 활주, 이륙, 착륙, 선회 대기, 강하 경로 수정 |

## 음성 경고 시스템

Betty라고 부르는 F-15C 음성 경고는 긴급 기체 상태와 고장을 알립니다.

| 조건 | 음성 메시지 |
| --- | --- |
| 오른쪽 엔진 화재 | `Engine fire right` |
| 왼쪽 엔진 화재 | `Engine fire left` |
| 비행 제어 손상 | `Flight controls` |
| 착륙장치 전개 상태에서 안전 속도 초과 | `Gear down` |
| ILS 접근 중 착륙장치 미전개 | `Gear up` |
| Bingo 설정 연료 도달 | `Bingo fuel` |
| 연료 부족 | `Fuel 1500`, `Fuel 800`, `Fuel 500` |
| 자동 조종·제어 계통 고장 | `ACS failure` |
| 항법 컴퓨터 고장 | `NCS failure` |
| ECM 고장 | `ECM failure` |
| 유압 고장 | `Hydraulics failure` |
| 레이더 고장 | `Radar failure` |
| 최대 G 초과 | `Maximum G` |
| 최대 받음각 초과 | `Maximum angle of attack` |
| 임계 속도 | `Critical speed` |
| 미사일 경고 | `Missile` 뒤에 시계 방향과 높음/낮음 안내가 이어집니다. |

음성 경고를 우선 처리하세요. 위협이나 고장을 인식하고 먼저 기체를 조종한 뒤 설정 수정이나 방어를 수행합니다.
