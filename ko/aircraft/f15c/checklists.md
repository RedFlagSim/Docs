# F-15C 운용 체크리스트

매뉴얼 절차를 조종석에서 바로 사용할 단계로 정리했습니다. DCS F-15C 매뉴얼의 기본 키 설정을 전제로 하며 자신의 조종 설정에 맞게 조정할 수 있습니다.

## 엔진 시동

1. 항법등 켜기: `[Right Ctrl + L]`
2. 캐노피 닫기: `[Left Ctrl + C]`
3. 왼쪽 엔진 시동 및 스로틀 아이들: `[Right Alt + Home]`
4. 오른쪽 엔진 시동 및 스로틀 아이들: `[Right Ctrl + Home]`
5. RPM, FTIT, 연료 유량, 경고등 확인.

## 지상 활주와 이륙

1. RPM과 FTIT 안정 확인.
2. 스로틀을 조금씩 조정하며 지상 활주.
3. 러더/앞바퀴 조향으로 경로 유지.
4. 필요시 제동: `[W]`
5. 이륙 전 플랩 내리기: `[F]`
6. 활주로 중심선에 정렬하고 정지.
7. 밀리터리 또는 최대 추력으로 증가.
8. 약 100노트에서 부드럽게 기수를 들어 10~12도 피치 확보.
9. 상승 확인 후 착륙장치 올리기: `[G]`
10. 플랩 올리기: `[F]`

## 항법

1. NAV 모드 선택: `[1]`
2. 경로점 전환: `[Left Ctrl + ~]`
3. HUD 유도와 HSI 방위 따르기.
4. 거리와 남은 시간 교차 확인.
5. 고도, 연료, 위협 상태 계속 확인.

## 착륙

1. 착륙/ILSN 경로점 선택.
2. 착륙장치 전개 전 250노트 미만으로 감속.
3. 착륙장치 내리기: `[G]`
4. 플랩 내리기: `[F]`
5. 최종 접근을 약 180노트로 안정.
6. 20~22 받음각 단위 유지.
7. 접지 후 스로틀 아이들.
8. 기수 위 약 13도로 공력 제동.
9. 약 90노트 미만에서 기수 내리기.
10. 필요시 휠 브레이크: `[W]`

## AIM-120 AMRAAM

1. 레이더 켜기: `[I]`
2. LRS 또는 TWS 선택: `[2]` 또는 `[Right Ctrl + I]`
3. 중거리 미사일 선택: `[D]`
4. TDC를 표적 위로 이동: `[;]`, `[,]`, `[.]`, `[/]`
5. 표적 잠금 또는 지정: `[Enter]`
6. 거리, 유도, 식별 확인.
7. 발사: `[Right Alt + Space]`
8. 전술상 가능하면 활성화까지 지원.

## AIM-7 Sparrow

1. 레이더 켜기: `[I]`
2. LRS 선택: `[2]`
3. 무장 선택으로 AIM-7 선택: `[D]`
4. 표적을 STT로 잠금: `[Enter]`
5. 유효 거리와 ASE 유도 확인.
6. 발사: `[Right Alt + Space]`
7. 명중까지 레이더 잠금 유지.

## AIM-9 Sidewinder

1. 필요시 ACM 선택: 수직 탐색 `[3]`, 보어사이트 `[4]`.
2. 무장 선택으로 AIM-9 선택: `[D]`
3. 표적을 탐색기 시야에 넣기.
4. 필요시 케이지/언케이지: `[6]`
5. 탐색기 신호음과 유효 거리 대기.
6. 발사: `[Right Alt + Space]`

## M61 기관포

1. 기관포 선택: `[C]`
2. 가능하면 레이더 잠금 또는 AACQ 사용.
3. 표적을 계산 조준점 또는 퍼널 안에 배치.
4. 짧게 점사: `[Space]`
5. 접근률을 재평가하고 오버슈트를 피하기.
