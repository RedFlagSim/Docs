# 사용자 의견

우리는 사용자의 제안과 피드백을 매우 소중하게 생각합니다. 플레이 중 버그를 발견하거나, 게임 개선 제안이 있거나, 그 외 전하고 싶은 말씀이 있다면 언제든지 이메일로 연락해 주십시오.

::: tip 힌트
직접적인 이메일 피드백은 현재 가장 효과적인 소통 방식입니다. 모든 메시지를 꼼꼼히 읽고 향후 업데이트를 통해 게임 경험을 지속적으로 개선해 나가겠습니다.
:::

## 의견 보내는 법

개발자 이메일 주소로 직접 메일을 보내실 수 있습니다:

<div class="feedback-card">
  <p><strong>개발자 이메일:</strong></p>
  <p><a href="mailto:support@redflagsim.com?subject=Red%20Flag%20Sim%20Feedback" class="email-link">support@redflagsim.com</a></p>
</div>

### 권장 포함 정보
문제를 신속하게 파악하거나 제안을 더 잘 이해할 수 있도록 이메일에 다음 내용을 포함해 주시기를 권장합니다:
*   **의견 유형**: 버그 보고 / 기능 제안 / 기타
*   **기기 모델**: 예: iPhone 15 Pro, iPad Pro (M2)
*   **iOS 버전**: 예: iOS 17.4
*   **상세 설명**: 문제 재현 단계 또는 제안의 구체적인 내용
*   **스크린샷/동영상**: 관련 시각 자료가 있는 경우 첨부 파일로 보내 주십시오
