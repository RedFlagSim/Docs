# Red Flag Sim 개인정보 처리방침

**시행일: 2026년 5월 7일**

본 개인정보 처리방침은 **株式会社ブルードット(BLUEDOT Inc.)**(이하 "당사")가 제공하는 모바일 기기용 애플리케이션 **Red Flag Sim**(이하 "본 앱")에 적용됩니다.

당사는 사용자의 개인정보를 소중히 여깁니다. 본 앱 자체는 사용자의 실명, 주소, 전화번호, 정밀한 지리적 위치, 연락처, 사진, 마이크 또는 카메라 내용을 능동적으로 수집하지 않습니다. 본 앱은 주로 [Unity Gaming Services](https://unity.com/solutions/gaming-services)를 사용하여 사용자 인증, 플레이어 식별, 클라우드 저장, 인앱 결제 처리 및 관련 게임 서비스를 제공합니다.

본 앱을 사용하는 것은 본 개인정보 처리방침에 설명된 데이터 처리 방식에 동의함을 의미합니다.

## 1. 당사가 처리할 수 있는 정보

### 1.1 사용자 인증 및 계정 정보

본 앱은 플레이어 로그인, 계정 식별, 기기간 데이터 동기화 및 게임 서비스 액세스를 위해 [Unity Authentication](https://docs.unity.com/ugs/en-us/manual/authentication/manual/privacy-overview) 및/또는 [Unity Player Accounts](https://docs.unity.com/ugs/en-us/manual/authentication/manual/data-privacy-unity-player-accounts)를 포함한 Unity Gaming Services를 사용합니다.

사용자가 선택한 로그인 방법에 따라 Unity는 다음 정보를 처리할 수 있습니다.
*   Unity가 생성한 고유 플레이어 ID
*   인증 토큰 또는 로그인 상태 정보
*   Unity Player Accounts 관련 계정 정보
*   사용자가 이메일 로그인을 선택한 경우 이메일 주소 포함 가능
*   계정 보안, 로그인 상태 및 서비스 액세스와 관련된 필수 기술 데이터

이 정보는 주로 플레이어 계정 식별, 플레이어 데이터 복구, 게임 진행 상황 저장 및 게임 서비스 보안 보장을 위해 사용됩니다. Unity의 게임 플레이어 및 앱 사용자 개인정보 처리방침에 따르면, Unity는 Unity 기술을 사용하는 제3자 앱을 통해 수집하거나 수신한 정보를 처리합니다.

*   게임 진행 상황
*   클라우드 저장 데이터
*   게임 내 설정
*   해제된 콘텐츠
*   구매한 콘텐츠의 소유 상태
*   비행 훈련 기록
*   조종사 인증 상태
*   인증 유효 기간, 갱신 상태 및 관련 점수 데이터
*   게임 서비스 운영과 관련된 필수 데이터

이 데이터는 저장 데이터 복구, 진행 상황 동기화, 해제된 콘텐츠 기록, 사용자 설정 저장, 인증 시스템 관리 및 계정 데이터 일관성 유지 등 정상적인 게임 경험을 제공하기 위해 사용됩니다.
