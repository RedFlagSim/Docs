# 계정과 프로필

Red Flag Sim 프로필은 진행, 비행 일지, 순위, 자격과 메달에 사용하는 플레이어 신원입니다.

## 계정 종류

익명 계정으로 빠르게 체험할 수 있지만 현재 저장된 계정 상태에 연결됩니다.

장기적으로 플레이하려면 Unity ID를 연결하거나 해당 ID로 로그인하세요. 재설치나 기기 변경 후에도 같은 신원으로 진행을 유지하려면 연결된 계정이 더 안전합니다.

## 프로필 내용

- 조종사 표시 이름.
- 호출부호.
- 비행대대 또는 편대 정보.
- 국가.
- 계급과 하위 단계.
- 경력 XP.
- 총 비행 시간.
- 진행에 사용하는 연속 로그인과 활동 이력.

순위표와 공개 화면은 표시 이름, 호출부호, 아바타, 계급, 하위 단계, XP 등 축약된 공개 프로필을 사용합니다.

## 진행 보호

진행은 로그인한 계정에 속합니다. 계정을 바꾸면 해당 계정의 프로필, 기록, 자격과 메달로 전환됩니다.

익명 플레이 중이라면 중요한 장기 진행을 쌓기 전에 계정 연결을 고려하세요. 조종사 신원을 보존하고 나중에 진행을 복구하기 쉬워집니다.

## 프로필 갱신 시점

- 로그인 후.
- 비행 일지를 열 때.
- 비행이나 기술 이벤트 완료 후.
- 경력 XP를 받은 후.
- 자격 취득 또는 갱신 후.
- 메달 해제 후.
