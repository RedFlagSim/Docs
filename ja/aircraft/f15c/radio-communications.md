# F-15C 無線通信

無線は F-15C を編隊、AWACS/GCI、管制、地上員と結びます。基本形式は呼び出す相手、要求する動作、実行に必要な戦術情報です。

## メッセージ構成

1. 呼出符号：受信者と発信者。例：`Chevy 22, Chevy 21`。
2. 命令・報告：動作や状態。例：`engage bandits`、`missile launch`。
3. 詳細：方位、距離、高度、目標種別、時計方向、結果など。

短く正確に伝えてください。戦闘中の無線時間も資源です。

## 編隊・僚機指令

| 指令群 | 用途 |
| --- | --- |
| Engage my target | プレイヤーの指定目標を攻撃 |
| Engage bandits | 空中敵機を捜索・攻撃 |
| Cover me | プレイヤーへの最も差し迫った脅威に対処 |
| Rejoin | 編隊に復帰 |
| Go to route / RTB | 予定航路へ進む、または基地へ帰投 |
| Radar on/off | 僚機レーダーの送信制御 |
| ECM on/off | 僚機の妨害制御 |
| Smoke on/off | 目視識別や曲技用スモーク |
| Formation commands | 間隔と隊形を調整 |

僚機は通常 `Copy`、`Roger`、`Affirm` と短く応答し、実行できない場合は `Negative`、`Unable` と返答します。

## AWACS・GCI への要求

F-15C のレーダーが沈黙中、妨害下、別方向に集中している場合、早期警戒機や地上管制から戦術状況を得られます。

| 要求 | 返される情報 |
| --- | --- |
| Bogey dope | 最寄りの敵機・不明機の方位、距離、高度、アスペクト |
| Picture | 区域内で検知した機群の概要 |
| Vector to home plate | 最寄りの適切な友軍飛行場への方位と距離 |
| Vector to tanker | 最寄りの友軍給油機への方位と距離 |

報告の質はセンサー範囲と陣営の把握状況に依存します。レーダー、TEWS、目視による確認を続けてください。

## 航空交通管制

ATC は地上移動、離陸、進入、着陸に使用します。主な要求：

- 地上走行許可
- 離陸許可
- 帰投・進入要求
- 着陸許可
- 着陸復行・間隔指示

進入中は滑走路、コース、他機との間隔、グライドパス修正が伝えられる場合があります。

## 地上員

有効な基地やサービス区域で駐機中に使用できます。任務条件に応じて給油、再武装、修理、搭載変更を行います。

## 他ユニットからの無線

| 発信元 | 意味の例 |
| --- | --- |
| 僚機 | 離陸滑走、脚上げ、再集合、交戦、防御、帰投 |
| 僚機の兵器通報 | `Fox One`、`Fox Two`、`Fox Three`、`Guns`、`Winchester` |
| 僚機の脅威通報 | レーダーロック、地上レーダーロック、ミサイル発射、SAM 発射 |
| AWACS/GCI | 敵情、近接交差警告、脅威なし、誘導 |
| ATC | 地上走行、離陸、着陸、旋回待機、降下経路修正 |

## 音声警報システム

Betty と呼ばれる F-15C の音声警報は、緊急の機体状態や故障を知らせます。

| 条件 | 音声 |
| --- | --- |
| 右エンジン火災 | `Engine fire right` |
| 左エンジン火災 | `Engine fire left` |
| 飛行制御の損傷 | `Flight controls` |
| 脚下げ時に安全速度超過 | `Gear down` |
| ILS 進入中に脚が上がっている | `Gear up` |
| 燃料が Bingo 設定に到達 | `Bingo fuel` |
| 燃料低下 | `Fuel 1500`, `Fuel 800`, `Fuel 500` |
| 自動操縦・制御系統の故障 | `ACS failure` |
| 航法コンピューター故障 | `NCS failure` |
| ECM 故障 | `ECM failure` |
| 油圧故障 | `Hydraulics failure` |
| レーダー故障 | `Radar failure` |
| 最大 G 超過 | `Maximum G` |
| 最大迎角超過 | `Maximum angle of attack` |
| 臨界速度 | `Critical speed` |
| ミサイル警報 | `Missile` に時計方向と高低の案内が続きます。 |

警報を優先事項として扱ってください。脅威や故障を認識し、まず操縦を維持してから、設定修正や防御を行います。
