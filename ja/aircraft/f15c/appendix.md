| BFM | 基本戦闘機機動 |
| BORE | ボアサイト捕捉モード |
| BVR | 視程外 |
| CAS | 操縦補助システム |
| DCS | Digital Combat Simulator |
| ECM | 電子対抗手段 |
| EOS | 光電子システム |
| EW | 電子戦 |
| FC | 射撃管制 |

| TWS | 捜索中追尾 |

| WCS | 兵器管制システム |
| WVR | 視程内 |
