# F-15C 操作チェックリスト

マニュアルの手順を操縦席ですぐ使える形にまとめたものです。DCS F-15C マニュアルの標準キー割り当てを前提とし、自分の操作設定に合わせて変更できます。

## エンジン始動

1. 航法灯オン：`[Right Ctrl + L]`
2. キャノピーを閉じる：`[Left Ctrl + C]`
3. 左エンジン始動、スロットルをアイドルへ：`[Right Alt + Home]`
4. 右エンジン始動、スロットルをアイドルへ：`[Right Ctrl + Home]`
5. RPM、FTIT、燃料流量、警告灯を確認。

## 地上走行と離陸

1. RPM と FTIT の安定を確認。
2. スロットルを少しずつ調整して地上走行。
3. ラダー／前輪操向で走行線を維持。
4. 必要に応じてブレーキ：`[W]`
5. 離陸前にフラップを下げる：`[F]`
6. 滑走路中心線に合わせて停止。
7. ミリタリー推力または最大推力へ。
8. 約 100 ノットで滑らかに機首を上げ、10～12 度のピッチを確立。
9. 上昇を確認して脚を上げる：`[G]`
10. フラップを上げる：`[F]`

## 航法

1. NAV モード選択：`[1]`
2. 経路点を切り替える：`[Left Ctrl + ~]`
3. HUD の誘導と HSI の方位に従う。
4. 距離と残り時間を照合。
5. 高度、燃料、脅威を継続監視。

## 着陸

1. 着陸／ILSN 経路点を選択。
2. 脚を下げる前に 250 ノット未満へ減速。
3. 脚を下げる：`[G]`
4. フラップを下げる：`[F]`
5. 最終進入を約 180 ノットで安定。
6. 20～22 迎角単位を維持。
7. 接地してスロットルをアイドルへ。
8. 機首上げ約 13 度で空力ブレーキ。
9. 約 90 ノット未満で機首を下げる。
10. 必要に応じて車輪ブレーキ：`[W]`

## AIM-120 AMRAAM

1. レーダーオン：`[I]`
2. LRS または TWS 選択：`[2]` または `[Right Ctrl + I]`
3. 中距離ミサイル選択：`[D]`
4. TDC を目標へ移動：`[;]`、`[,]`、`[.]`、`[/]`
5. 目標をロック／指定：`[Enter]`
6. 距離、誘導、識別を確認。
7. 発射：`[Right Alt + Space]`
8. 戦術上可能ならアクティブ化まで支援。

## AIM-7 Sparrow

1. レーダーオン：`[I]`
2. LRS 選択：`[2]`
3. 武器選択で AIM-7 を選ぶ：`[D]`
4. STT で目標をロック：`[Enter]`
5. 有効射程と ASE 誘導を確認。
6. 発射：`[Right Alt + Space]`
7. 命中までレーダーロックを維持。

## AIM-9 Sidewinder

1. 必要なら ACM を選択：垂直走査は `[3]`、ボアサイトは `[4]`。
2. 武器選択で AIM-9 を選ぶ：`[D]`
3. 目標をシーカー視野内へ。
4. 必要に応じてケージ／アンケージ：`[6]`
5. シーカー音と有効射程を待つ。
6. 発射：`[Right Alt + Space]`

## M61 機関砲

1. 機関砲選択：`[C]`
2. 利用可能ならレーダーロックまたは AACQ を使用。
3. 目標を計算照準またはファンネル内へ。
4. 短いバースト射撃：`[Space]`
5. 接近率を再評価し、オーバーシュートを防ぐ。
