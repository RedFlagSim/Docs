# F-15C 防御システム

F-15C の防御装備は、能動的な電子対抗手段、受動的なレーダー警報、チャフとフレアを組み合わせています。パイロットは脅威表示を理解し、妨害を行うか判断し、機動とともに適切な対抗手段を使用します。

<a id="rwr"></a>

## 戦術電子戦システム（TEWS）

TEWS は AN/ALR-56C レーダー警報受信機を使用して、航空機、艦船、地上システムのレーダー電波を検知します。受信機は受動式なので、自ら電波を送信して F-15C の存在を知らせることはありません。

TEWS 表示は自機シンボルを中心とします。信号の角度は自機に対する方位を表します。<strong>中心からの距離は脅威度を表し、実際の距離ではありません。</strong>

### 3. 3段階の脅威度

<a :href="rwrThreatImage" target="_blank" rel="noopener">
  <img :src="rwrThreatImage" alt="TEWS 図3：内側にロックオン中の脅威、中間領域の左側に未ロックオンの新しい11、外側に捜索信号" loading="lazy" />
</a>

TEWS は脅威度に応じて、中心から外側へ3つの領域に信号を配置します。

| 表示領域 | 脅威度 | 例 |
| --- | --- | --- |
| 最内側 | 高 | 自機をロックオンしているレーダー、ミサイル、その他の優先度が高い脅威。 |
| 中間 | 中 | 検知済みですが、まだ自機をロックオンしていない射撃管制レーダー。 |
| 最外側 | 低 | この例の捜索レーダーなど、脅威度が最も低い信号。 |

図3の左側にある新しい `11` には半円が付き、新しい信号であることを示しています。この射撃管制レーダーはまだ自機をロックオンしていないため、中程度の脅威に分類され、中間領域に表示されます。

<strong>中心に近いシンボルほど脅威度が高く、電波源が実際に近いという意味ではありません。</strong> 方位、電波源の種類、ロックオン表示を合わせて脅威を判断してください。

<a id="rwr-audio"></a>

### 4. 警報音

TEWS は走査、新しい信号、ロックオン、ミサイル発射を異なる音で知らせます。

| 状況 | 警報音 | 関連する表示 |
| --- | --- | --- |
| レーダーが自機を走査 | 走査音が1回鳴ります。 | 対応するレーダー信号。 |
| 新しい信号が出現 | 特徴的な、やや高い音が3回繰り返されます。 | 信号の上に半円が現れます。 |
| 射撃管制レーダーが自機をロックオン | 走査音が連続して繰り返されます。 | 信号を囲む完全な円が現れます。 |
| 自機にレーダー誘導ミサイルが発射される | 高いミサイル発射警報音が素早く4回鳴ります。 | 同時に対応する信号の円が点滅します。 |

## チャフとフレア

チャフはレーダー誘導の脅威に、フレアは赤外線誘導の脅威に使用します。コックピットの表示灯は放出中に点滅し、残量が少なくなると警告します。

対抗手段は機動と組み合わせることで効果を発揮します。

1. 旋回して、ミサイルが容易に見越し追尾できないようにします。
2. レーダー誘導ミサイルには、ビーム機動やノッチ機動中にチャフを使用します。
3. 赤外線ミサイルが疑われる場合は、機体の向きと熱放射の見え方を変えながらフレアを使用します。
4. 放出後は予測しやすい直線飛行を避けます。
5. 最初の回避旋回後に TEWS を再確認し、脅威を回避できたと思い込まないでください。
