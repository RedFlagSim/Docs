# F-15C コックピット計器

F-15C のコックピットは HUD、垂直状況ディスプレイ（VSD）、戦術電子戦システム（TEWS）の3つを戦闘時の中心的な表示とします。エンジン、航法、燃料、武装、対抗手段の計器をその下や周囲に配置し、戦闘に集中しながら機体状態を照合できます。

## 戦闘用ディスプレイ

<a id="instrument-3"></a>

### 垂直状況ディスプレイ（VSD）

VSD は F-15C のレーダー表示です。捜索空域、目標反射、ロック状態、視程外戦闘用の目標詳細を示します。操作とシンボルはレーダーの章で説明します。

![垂直状況ディスプレイ（VSD）](/assets/F-15C/Manual/fig-21-vsd.png)

<a id="instrument-9"></a>

### 戦術電子戦システム（TEWS）

TEWS はレーダー警報を表示します。自機シンボルの周囲に電波源を示し、最も危険な脅威を優先し、ミサイル発射表示と ECM 状態を示します。

![戦術電子戦システム（TEWS）](/assets/F-15C/Manual/fig-22-tews-display.png)

<a id="instrument-1"></a>

### 多目的カラーディスプレイ／兵器管制パネル

#### SIT 状況表示

SIT は戦場を上から見た形で表示します。データリンクで自機、友軍機、敵機の情報を示します。各種ジオフェンス、コンパス、Zulu 時刻、ブルズアイ座標も表示できます。カーソルは VSD に追従させるか、追従を解除して独立操作できます。

![SIT 状況表示](/assets/F-15C/Manual/fig-23-mpcd-sit-display.png)

#### AA 兵器状態パネル

![AA 兵器状態パネル](/assets/F-15C/Manual/fig-23-mpcd-weapons-panel.png)

AA ページは外部タンク、武器種別、機関砲弾数、チャフとフレア残数を表示します。`FUEL` は搭載タンク、`PYLON` は空の搭載位置です。武器選択と表示全体は [MPCD 章](/ja/Docs/aircraft/f15c/mpcd.html)を参照してください。

## 飛行計器

<a id="instrument-12"></a>

### 着陸装置レバー

着陸装置の展開と格納を指令します。

<a id="instrument-13"></a>

### 着陸装置位置表示

着陸装置が下がり、固定されたことを確認します。

<a id="instrument-2"></a>

### 指示対気速度とマッハ数

MPCD の右側にあります。固定目盛は 50～1000 ノットの指示対気速度を示します。マッハ指針はおよそ 200 ノット以上で有用になります。

![指示対気速度とマッハ数](/assets/F-15C/Cockpit/indicated-airspeed-mach.png)

<a id="instrument-14"></a>

### 迎角指示器

幾何学的な角度ではなく F-15 の迎角単位で表示します。進入、低速機動、大迎角からの回復に使用します。通常の着陸目標は約 20～22 単位です。

![迎角指示器](/assets/F-15C/Manual/fig-25-aoa-indicator.png)

<a id="instrument-15"></a>

### 加速度計

現在の G と、出撃中の最大正負 G を記録します。激しい機動後に構造へかかった荷重を照合する参考にします。

![加速度計](/assets/F-15C/Cockpit/accelerometer.png)

### 中央の ADI、HSI と周辺操作部

![中央の ADI、HSI と周辺操作部](/assets/F-15C/Cockpit/adi-hsi-emergency-jettison-steering-mode.png)

<a id="instrument-4"></a>

#### 姿勢指示器（ADI）

ADI は主要なピッチ・バンクの基準です。回転球はピッチ 5 度刻み、バンク 10 度刻みで、30 度ごとに大きな印があります。縦横の指示棒は選択した航法源による操縦指令を示し、下部の旋回・横滑り表示は釣り合いの取れた旋回を助けます。利用可能な場合、隣の切替器で INS または AHRS の姿勢基準を選びます。

<a id="instrument-16"></a>

#### 水平状況指示器（HSI）

HSI は航法状況を平面図で示します。回転コンパスの上部指標に自機方位が位置し、コース矢印と偏位バーが選択コースと横方向の誤差を示します。左上のカウンターは海里距離、右上は選択コースです。COURSE SET と HEADING SET ノブで対応する基準を調整します。ILS 進入では ADI と HUD の誘導と併せてコース偏位を読みます。

<a id="instrument-22"></a>

#### 緊急投棄ボタン

ADI のすぐ左にある保護付き黄黒の <strong>PUSH TO JETT</strong> ボタンは、対象となる外部搭載物を緊急投棄します。直ちに荷重を減らす必要がある場合だけ使用します。投棄される品目は現在の機体構成とミッション規則によります。

<a id="instrument-23"></a>

#### 誘導モード切替器

緊急投棄ボタンの下の切替器で HSI、ADI、HUD の誘導情報源を選びます。

- <strong>NAV：</strong>航路・航法点誘導。
- <strong>TCN：</strong>TACAN 方位、距離、選択コース誘導。
- <strong>ILS NAV：</strong>ILS ローカライザーとグライドスロープを NAV 誘導と併用。
- <strong>ILS TCN：</strong>ILS 誘導を TACAN 誘導と併用。

<a id="instrument-17"></a>

### 機内時計

コックピットの時刻基準で、ミッションの時刻管理と航法照合に使う Zulu 時刻を表示します。

![機内時計](/assets/F-15C/Cockpit/aircraft-clock.png)

### 高度計と昇降計

![高度計と昇降計](/assets/F-15C/Cockpit/altimeter-vvi.png)

<a id="instrument-6"></a>

#### 気圧高度計

カウンターと指針でフィート高度を示します。ドラムは主要な高度値、指針は細かな値を表示します。気圧設定ノブで必要な現地設定値を入力します。設定が誤っていると表示高度も誤ります。

<a id="instrument-5"></a>

#### 昇降計（VVI）

VVI は上昇・降下率を毎分千フィートで示します。時計回りは上昇、反時計回りは降下です。

## エンジン・燃料計器

### エンジン回転数と温度

![エンジン回転数と温度](/assets/F-15C/Cockpit/tachometer-ftit.png)

<a id="instrument-8"></a>

#### 回転計

左右の回転計はエンジン回転数を 0～110% で示します。始動、地上走行、離陸点検、スロットル確認で指針とカウンターを併用します。

<a id="instrument-7"></a>

#### ファンタービン入口温度（FTIT）

左右の FTIT 計は 0～1400 °C のタービン温度を示します。指針は連続的な表示、カウンターは値の確認を助けます。異常な高温は過熱を示し、速やかな注意が必要です。

### 燃料流量と排気ノズル位置

![燃料流量と排気ノズル位置](/assets/F-15C/Cockpit/fuel-flow-nozzle-position.png)

<a id="instrument-18"></a>

#### エンジン燃料流量

アフターバーナー分を含むエンジンへの総燃料供給をポンド毎時で示します。燃料量表示と併用し、消費量やエンジン・燃料系統の異常を確認します。

<a id="instrument-19"></a>

#### エンジンノズル位置

全開を基準とした排気ノズル開度の割合を示します。開度は出力やアフターバーナー作動により変化します。

### 油圧とエンジン油圧

![油圧とエンジン油圧](/assets/F-15C/Cockpit/hydraulic-oil-pressure.png)

<a id="instrument-24"></a>

#### 油圧系統圧力計

3つの計器が <strong>PC1</strong>、<strong>PC2</strong>、<strong>UTIL</strong> を 0～4000 psi で示します。PC1 と PC2 は飛行制御、UTIL は脚、ブレーキ、前輪操向などに供給します。通常は約 3000 psi で、大幅な低下やゼロ表示は影響を受けた系統の識別に役立ちます。

<a id="instrument-25"></a>

#### エンジン潤滑油圧計

下部の2つは左右エンジンの油圧を 0～100 psi で示します。両方を比較し、低い値は対応する注意表示と照合します。

<a id="instrument-10"></a>

### 燃料量

指針は機内総燃料を千ポンド単位で示します。上部カウンターは総燃料、下部 LEFT・RIGHT と切替器は個別タンクの量や表示器の点検に使います。

![燃料量](/assets/F-15C/Cockpit/fuel-quantity.png)

## 圧力と対抗手段

<a id="instrument-20"></a>

### キャビン圧力計

相当キャビン高度を示します。損傷や与圧故障で表示が 10000 フィートに近づく場合は速やかに降下します。

![キャビン圧力計](/assets/F-15C/Cockpit/cabin-pressure.png)

<a id="instrument-11"></a>

### チャフ・フレア表示灯

放出時に約3秒点滅します。残量が危険なほど少ない場合、最少残量の警告灯が点灯します。

![チャフ・フレア表示灯](/assets/F-15C/Cockpit/chaff-flare-indicators.png)

<a id="instrument-21"></a>

### 警告灯パネル

機体システムの警告を表示します。
