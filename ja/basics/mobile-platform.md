# モバイル版操縦マニュアル

この文書は iOS/Android のモバイル端末を対象とします。

## 基本ルール：画面を垂直に持つ

正確な姿勢制御を行うための基本手順です。

![基本ルール：画面を垂直に持つ](/assets/tilt-guide.png)

- ❌ 誤り：端末を水平に寝かせる持ち方。ロール軸とヨー軸が結合し、ロール入力を確実に識別できなくなります。
- ✅ 基準：両手で端末を持ち、画面を地面に対して垂直にして自分に向けます。

### なぜ垂直に持つ必要があるのか？

モーション操作ではロール軸を明確に識別する必要があります。端末を寝かせると姿勢計算時にロール軸とヨー軸が結合し、ロールとヨーの入力を確実に区別できません。そのため、端末を立てた状態を基準姿勢にします。

## 操作入力

- ピッチ（昇降舵）：端末の上部を後ろ、自分の体へ傾けると機首を上げて上昇します。前、自分から離れる方向へ傾けると機首を下げて降下します。
- ロール（補助翼）：ハンドルを回すように端末を左右に回転させます。

## タッチ式仮想スティック

モバイル版ではモーション操作の代わりに画面上の仮想スティックも使用できます。端末を動かさずに操縦したい場合は、飛行前に仮想スティックの操作モードを選択してください。

![タッチ式仮想スティック](/assets/mobile-virtual-stick.jpeg)

- ピッチ：スティックを下へドラッグすると機首上げ、上へドラッグすると機首下げです。
- ロール：左右へドラッグすると対応する方向へロールします。
- 中立復帰：指を離すと自動的に中央へ戻ります。

垂直に持つことと較正の要件はモーション操作だけに適用されます。タッチ式スティックでは見やすい姿勢で端末を持てます。

## 飛行前の設定と精密操作のヒント

1. 基準設定（較正）：コックピットに入った後または離陸前に、楽な座り方で端末を安定して立て、メインメニューの Calibrate Gyro をタップします。現在の角度が中立のゼロ点として記録されます。

    ![飛行前の設定と精密操作のヒント](/assets/mobile-gyro-calibration.jpeg)

2. 操作を安定させる：密集編隊、空中給油、近距離空戦では、肘を膝や肘掛けに置きます。体の震えを抑え、1度未満の精密な操作につながります。

## タッチ UI 編集モード

画面の空白部分を素早く4回連続でタップすると編集モードが開きます。メインメニューの `UI Editor` からも開けます。

![タッチ UI 編集モード](/assets/mobile-ui-editor.jpeg)

編集モードでは次の操作ができます。

- コントロールの再配置：選択して移動し、画面の配置を変更します。
- 透明モード：`CLEAR MODE` で透明な表示に切り替えます。
- 全体の不透明度：タッチ UI による視界の遮りを減らします。
- フローティング MFD：多機能ディスプレイのサイズと表示を調整します。詳しくは [F-15C タッチ UI](/ja/Docs/aircraft/f15c/touch-ui.html#item-3)を参照してください。
