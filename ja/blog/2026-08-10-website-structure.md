# Webサイト構成変更のお知らせ

RedFlagSim はドキュメント専用サイトから、完全な公式Webサイトへ移行しています。

Docs は操作ガイド、機体モジュール、ゲームシステム資料を引き続き提供します。新しい構成では Dev Blog、Support、独立した About ページを追加しました。

ドキュメントはマニュアル、プラットフォームガイド、機体モジュール、ゲームシステム資料の場所として残ります。新構成では製品への明確な入口、分類した資料ナビゲーション、開発更新専用ブログを追加します。

## 変更の理由

プロジェクトには参考資料以上のものが必要です。シミュレーターの成長に合わせ、製品の説明、現在の開発方針、リリースノートや技術更新を継続して掲載する場所を整えます。

## 主な変更

- Docs を公式サイト内のひとつのモジュールとして整理。
- Dev Blog に開発情報と進捗を集約。
- Support にフィードバック、ポリシー、公式チャンネルを集約。
- VitePress のレイアウトに RedFlagSim の赤いアクセントを適用。

ナビゲーションはドキュメント、開発ブログ、概要、サポートで構成します。
