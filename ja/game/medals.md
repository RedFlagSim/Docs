# メダル

メダルは永久実績であり、期限付き資格と異なり取得後に失効しません。

## 獲得方法

保存済みの進行が節目に達すると授与されます。判定は飛行後、記録更新後、ログイン時、ログブックを開いたときなどに行われます。

現在の分類：

- 飛行時間の節目。
- キャリア XP の節目。
- 昇進。
- 空戦成果。
- ミサイル・機関砲の命中。
- 爆弾投下。
- 飛行場着陸の成績と回数。
- ブーム給油の成績と回数。

## 例

- 最初の記録された出撃を完了。
- 飛行時間 10、50、100、500 時間に到達。
- 主要なキャリア XP の節目に到達。
- 上位階級へ昇進。
- 初の空戦勝利。
- 高い着陸スコア。
- ブーム給油の節目を達成。

## 予約済みメダル系列

ロケット攻撃、艦船攻撃、空母着艦、特別な精密攻撃採点など、未完成の活動向けに準備された系列もあります。

対応するゲームプレイと採点処理が有効になるまでロックされる場合があります。

## メダル通知

解除時には簡単なポップアップが表示される場合があります。見逃した場合は、ログブックで未表示の通知を後から再表示できます。
