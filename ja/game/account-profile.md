# アカウントとプロフィール

Red Flag Sim のプロフィールは、進行、ログブック、ランキング、資格、メダルに使用するプレイヤーの身分情報です。

## アカウントの種類

匿名アカウントですぐに試せますが、現在保存されているアカウント状態に依存します。

長く遊ぶ場合は Unity ID を連携するか、それでログインしてください。再インストールや端末変更の際にも同じ身分で進行を保持するには、連携済みアカウントがより確実です。

## プロフィールの内容

- パイロットの表示名。
- コールサイン。
- 飛行隊や編隊の情報。
- 国。
- 階級とサブレベル。
- キャリア XP。
- 総飛行時間。
- 進行に使われる連続ログインと活動履歴。

ランキングなどでは、表示名、コールサイン、アバター、階級、サブレベル、XP などに絞った公開プロフィールを使います。

## 進行を守る

進行はログイン中のアカウントに属します。アカウントを切り替えると、そのプロフィール、記録、資格、メダルに切り替わります。

匿名で遊んでいる場合は、長期進行を蓄積する前の連携を検討してください。身分を保ち、後の進行復旧を容易にします。

## 更新されるタイミング

- ログイン後。
- ログブックを開いた後。
- 飛行や技能イベントを完了した後。
- キャリア XP の獲得後。
- 資格の取得・更新後。
- メダルの解除後。
