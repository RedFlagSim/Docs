# パッチ

パッチはゲーム内コレクションです。資格やメダルとは違い、獲得するとアカウントのコレクションとして保存されます。

実際の航空文化では、パッチはフライトスーツ、ジャケット、ヘルメット、ギアバッグ、待機室、部隊の壁などに使われます。飛行隊、派遣、演習、内輪のユーモア、節目の経験を表し、部隊同士で交換されることもあります。

Red Flag Sim では、パッチはアカウントに保存されるコレクションです。イベント、モジュール関連報酬、特別バンドル、ストア報酬、将来のコミュニティ活動などで入手できる予定です。

同じパッチを複数回受け取った場合、将来の交換やギフト機能に備えて追加分として保持されることがあります。今後はプロフィール表示、ログブック展示、限定パッチ、フレンド機能が利用可能になった後のギフト対応を目指します。
