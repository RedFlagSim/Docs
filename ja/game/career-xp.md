# キャリア XP

キャリア XP はパイロットの長期進行で、階級とサブレベルを上げ、さまざまなモジュールや活動の経験を表します。

## XP の獲得方法

- 毎日のログイン：連続ログイン報酬は 10 XP から始まり、継続すると 20 XP になります。
- 飛行時間：現在は有効な記録時間 5 分につき 5 XP。
- 武器活動：有効なプレイ記録のミサイル発射、機関砲射撃、命中、撃破が XP に寄与します。
- 着陸成績：飛行場着陸の高いスコア帯ではより多くの XP を獲得できます。
- 空中給油：給油完了、給油スコア向上、燃料の受け取りが XP に寄与します。
- 資格：現在は新規取得で 50 XP、更新で 15 XP。
- メダル：一部はメダルの等級に応じた追加 XP を付与します。

単純な稼ぎ行為ではなく実際の飛行・訓練を反映するため、価値の低い反復行動は制限される場合があります。

## 着陸と給油のスコア帯

より高い技能スコア帯は、より多くの XP に寄与します。

| 活動 | 結果 | XP |
| --- | ---: | ---: |
| 飛行場着陸 | 安全な着陸、70000 未満 | 5 |
| 飛行場着陸 | 70000+ | 15 |
| 飛行場着陸 | 85000+ | 60 |
| 飛行場着陸 | 95000+ | 150 |
| ブーム給油 | 給油完了 | 20 |
| ブーム給油 | 70000+ | 20 |
| ブーム給油 | 85000+ | 80 |
| ブーム給油 | 95000+ | 200 |

自己最高スコアが上位の帯へ改善すると、その帯の報酬を適用できます。

## 階級の進行

キャリア XP によって階級とサブレベルが上がります。各階級は 10 サブレベルです。現在の順序は次のとおりです。

1. Cadet（候補生）
2. SecondLt（少尉）
3. FirstLt（中尉）
4. Captain（大尉）
5. Major（少佐）
6. LtColonel（中佐）
7. Colonel（大佐）
8. BrigadierGeneral（准将）
9. MajorGeneral（少将）

XP の調整はゲームの発展に伴って変わる場合があります。プロフィールには保存済み XP から算出した現在の階級とサブレベルが表示されます。

## XP が表示されるタイミング

活動直後、飛行記録の同期後、ログブックを開いた後、または次のログイン後に表示されます。通知が遅れても、アカウント記録の同期後に進行を反映できます。
