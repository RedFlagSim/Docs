# ゲームシステム

Red Flag Sim は、パイロット名、Career XP、資格、メダルなどの進行状況をプレイヤーアカウントに保存します。これらは一回のプレイやローカル通知だけに依存するものではありません。

保存される内容には、プロフィール、総飛行時間、階級、サブレベル、スキル資格、永久メダルが含まれます。同期が遅れた場合でも、記録が反映されると報酬通知が後から出ることがあります。
