# ゲームシステム

Red Flag Sim はパイロットの進行状況をプレイヤーアカウントに保存します。プロフィール、キャリア XP、資格、メダルは単一の端末だけでなく、アカウントに紐づきます。

## 保存される情報

- プロフィール：名前、コールサイン、国、階級、サブレベル、XP、飛行時間。
- キャリア XP：飛行、訓練、戦闘、着陸成績、給油、毎日のログイン、資格、メダルによる長期進行。
- 資格：飛行場着陸やブーム式空中給油など、特定技能の期限付きまたは永久認定。
- メダル：飛行時間、昇進、戦闘成果、着陸、給油などの節目に対する永久実績。
- パッチ：アカウントのコレクションに保存される収集品。

## 進行状況の保存方法

ゲームは端末のポップアップや1回の飛行画面だけに依存しません。スコア、飛行記録、資格、メダルはアカウントの進行と照合され、プレイヤーの履歴に保存されます。

- 報酬はログイン中のアカウントに紐づきます。
- ゲームやログブックを開くと進行が更新されます。
- 一時的な通信障害で通知が遅れても、記録の同期後に反映できます。
- 今後のメダルや資格は、対応する活動が利用可能になるまでロックされる場合があります。
