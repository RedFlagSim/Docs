# Actualización de la estructura del sitio

RedFlagSim está pasando de un sitio dedicado a documentación a una web oficial completa.

Docs sigue siendo el lugar para guías, módulos de aeronaves y sistemas de juego. La nueva estructura incorpora Dev Blog, Support y una página About independiente.

La documentación sigue siendo el lugar de manuales, guías de plataformas, módulos de aeronaves y referencias de sistemas. La nueva estructura añade una entrada clara al producto, navegación agrupada y un blog dedicado a las novedades de desarrollo.

## Motivo del cambio

El proyecto necesita más que referencias. Al crecer el simulador, el sitio debe explicar el producto, mostrar el rumbo actual y ofrecer un lugar estable para notas de versión y novedades técnicas.

## Cambios principales

- Docs es un módulo dentro del sitio oficial.
- Dev Blog reúne notas y avances de desarrollo.
- Support concentra comentarios, políticas y canales oficiales.
- El diseño sigue las convenciones de VitePress con el rojo de RedFlagSim como acento.

La navegación se organiza en Documentación, Blog de desarrollo, Acerca de y Soporte.
