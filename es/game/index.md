# Sistemas de juego

Red Flag Sim guarda el progreso del piloto en la cuenta del jugador. El perfil, Career XP, calificaciones y medallas forman parte de tu historial a largo plazo, no solo de una notificación local tras una misión.

Se guardan nombre de piloto, indicativo, país, rango, subnivel, XP, tiempo total de vuelo, calificaciones, medallas y parches coleccionables. Si la sincronización se retrasa, una recompensa puede aparecer más tarde cuando el progreso se actualice.
