# Comunicaciones radio del F-15C

La radio conecta al F-15C con su formación, AWACS/GCI, ATC y personal de tierra. Los mensajes indican a quién se llama, qué se solicita y la información táctica necesaria.

## Estructura de mensajes

1. Indicativo: receptor y emisor, por ejemplo `Chevy 22, Chevy 21`.
2. Orden o informe: acción o estado, por ejemplo `engage bandits` o `missile launch`.
3. Detalles: marcación, distancia, altitud, tipo de objetivo, dirección horaria o resultado.

Sé breve y preciso. En combate, el tiempo de radio también es un recurso.

## Órdenes de formación y compañero

| Grupo de órdenes | Uso |
| --- | --- |
| Engage my target | Atacar el objetivo designado por el jugador |
| Engage bandits | Buscar y atacar enemigos aéreos |
| Cover me | Enfrentar la amenaza más inmediata al jugador |
| Rejoin | Regresar a la formación |
| Go to route / RTB | Seguir la ruta o regresar a la base |
| Radar on/off | Controlar las emisiones radar del compañero |
| ECM on/off | Controlar su interferencia |
| Smoke on/off | Identificación visual o humo acrobático |
| Formation commands | Ajustar separación y geometría |

Los compañeros suelen responder `Copy`, `Roger` o `Affirm`. Si no pueden cumplir, responden `Negative` o `Unable`.

## Solicitudes AWACS y GCI

Los controladores aéreos o terrestres proporcionan situación táctica cuando tu radar está apagado, interferido u ocupado en otra dirección.

| Solicitud | Información recibida |
| --- | --- |
| Bogey dope | Marcación, distancia, altitud y aspecto del enemigo o desconocido más cercano |
| Picture | Resumen de grupos detectados en la zona |
| Vector to home plate | Marcación y distancia a la base amiga adecuada más cercana |
| Vector to tanker | Marcación y distancia al cisterna amigo más cercano |

La calidad depende de la cobertura y la información del bando. Sigue verificando con radar, TEWS y observación visual.

## Control del tráfico aéreo

ATC se utiliza para movimiento terrestre, despegue, aproximación y aterrizaje. Solicitudes habituales:

- Permiso de rodaje
- Permiso de despegue
- Solicitud de regreso o aproximación
- Permiso de aterrizaje
- Instrucciones de motor y al aire o separación

En aproximación, la torre puede dar pista, curso, separación y correcciones de senda.

## Personal de tierra

Sus órdenes están disponibles estacionado en una base o zona de servicio válida. Según la misión, puede repostar, rearmar, reparar y modificar la carga.

## Mensajes de otras unidades

| Fuente | Significado de ejemplo |
| --- | --- |
| Compañero | Carrera de despegue, tren arriba, reunión, combate, defensa, regreso |
| Armas del compañero | `Fox One`, `Fox Two`, `Fox Three`, `Guns`, `Winchester` |
| Alertas del compañero | Fijación radar, fijación desde tierra, lanzamiento de misil o SAM |
| AWACS/GCI | Situación hostil, aviso de cruce cercano, sin amenazas, vectores |
| ATC | Rodaje, despegue, aterrizaje, órbita, corrección de senda |

## Sistema de avisos por voz

El sistema vocal del F-15C, llamado habitualmente Betty, avisa de estados urgentes y fallos.

| Condición | Mensaje de voz |
| --- | --- |
| Fuego en motor derecho | `Engine fire right` |
| Fuego en motor izquierdo | `Engine fire left` |
| Daños en controles de vuelo | `Flight controls` |
| Tren extendido sobre velocidad segura | `Gear down` |
| Tren no extendido en aproximación ILS | `Gear up` |
| Combustible al umbral bingo | `Bingo fuel` |
| Combustible bajo | `Fuel 1500`, `Fuel 800`, `Fuel 500` |
| Fallo del piloto automático/controles | `ACS failure` |
| Fallo del ordenador de navegación | `NCS failure` |
| Fallo ECM | `ECM failure` |
| Fallo hidráulico | `Hydraulics failure` |
| Fallo radar | `Radar failure` |
| G máxima superada | `Maximum G` |
| Ángulo de ataque máximo superado | `Maximum angle of attack` |
| Velocidad crítica | `Critical speed` |
| Alerta de misil | `Missile` seguido de dirección horaria e indicación alto/bajo. |

Da prioridad a las alertas. Reconoce la amenaza o fallo, pilota primero y después corrige la configuración o defiéndete.
