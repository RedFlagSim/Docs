# FAQ

## ¿Cuál es el estado actual del proyecto?

Red Flag Sim está en desarrollo activo. Los sistemas y la documentación se actualizan continuamente.

## ¿F-15C es el único módulo disponible ahora?

F-15C es actualmente el primer módulo central jugable. Hay módulos adicionales en desarrollo.

## ¿Cambiarán los sistemas entre versiones?

Sí. A medida que aumenta la fidelidad, el comportamiento de sistemas y flujos operativos puede ajustarse.

## ¿Cómo se mantienen las localizaciones?

El inglés es el idioma fuente. Las páginas localizadas se actualizan en paralelo y se validan con checks i18n en CI.
